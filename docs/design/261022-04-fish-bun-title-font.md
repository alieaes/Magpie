# 설계: 붕어빵 가게 — 제목 글꼴 (던파 비트비트체 v2)

[붕어빵 가게](./261021-01-fish-bun.md)의 게임 안 글자는 지금 모두 도트 글꼴 **갈무리11** 굵은 꼴이다([261022-01 §1-3](./261022-01-fish-bun-pixel-art.md)).
제목과 큰 숫자에 게임사가 공개한 도트 제목용 글꼴을 더해 "게임 화면" 느낌을 키운다. 본문은 갈무리11 그대로다.

## 2. 쓰는 곳

크게 보이는 글자만 바꾼다. 대사·말풍선·버튼·설명·강화 효과 글·돈 표시는 갈무리11 그대로다.

| 화면 | 글자 | 지금 크기(px) |
|---|---|---|
| 가게 | 간판 "까치 붕어빵", "N일째 아침" | 간판 높이의 42%, 46 |
| 장사 | "마감!", 콤보 숫자 | 96, 52 |
| 정산 | "N일째 장사 끝" | 44 |
| 가게 꾸리기 | 화면 제목 "가게 꾸리기" | 38 |
| 멈춤 | "잠깐 쉬는 중" | 40 |

- **크기**: 비트비트체의 계단이 또렷하게 보이는 크기를 화면에서 확인해 정한다(갈무리11의 11px 격자처럼 맞는 배수를 찾는다).
- 화면을 보고 어울리지 않는 곳은 빼거나 비슷한 큰 글자를 더할 수 있다. 위 표와 달라지면 구현 메모에 적는다.
- 관광객 대사(영어·일본어, [261022-03 §1-3](./261022-03-fish-bun-special-customers.md))는 본문이라 그 설계대로 갈무리11이다.
- `ART_STYLE = 'smooth'`(이전 그림체)일 때는 쓰지 않는다. 지금처럼 Pretendard다.

## 3. 라이선스와 파일

넥슨 공식 서체 안내(brand.nexon.com, 서체 FAQ)의 요지:

- 권리는 넥슨코리아에 있다. 개인·기업 모두 무료이고 상업 용도로 쓸 수 있다.
- **폰트 파일을 임의로 수정·편집해 재배포할 수 없다.** 글꼴 자체를 유료로 팔 수 없다.
- 저작권 안내를 포함하면 다른 소프트웨어와 **번들하거나 임베디드 폰트로 쓸 수 있다.**
- 출처 표기를 권장한다.
- 이 서체를 쓴 인쇄물·광고물(온라인 포함)은 넥슨 프로모션에 쓰일 수 있다고 적혀 있다.

그래서 이렇게 한다.

| 항목 | 방법 |
|---|---|
| 파일 | 넥슨이 배포한 TTF를 **그대로** 저장소에 넣는다(`games/fish-bun/assets/fonts/dnf-bitbit-v2/`). 쓰는 글자만 남기기(서브셋)나 woff2 변환은 하지 않는다 — 파일 수정으로 볼 여지가 있어서 |
| 저작권 안내 | 같은 폴더에 배포 파일에 들어 있는 안내문(없으면 FAQ 문구)을 둔다 |
| 출처 표기 | 스펙 `fish-bun.md`와 가게 꾸리기 화면 맨 아래 작은 글씨("글꼴: 던파 비트비트체 v2(넥슨), 갈무리11") |
| 받는 크기 | 넥슨 배포 zip이 약 1.2MB(TTF·OTF가 함께 들어 있다). TTF 한 파일 크기는 받아서 확인한다. 전송은 nginx·Cloudflare 압축에 맡긴다(파일 자체는 그대로) |
| 불러오기 | 게임을 열 때 갈무리11과 **함께** `FontFace`로 받는다(지금 `loadPixelFont`). 실패하면 갈무리11로 그린다(글꼴 목록 순서) |

- 갈무리11은 굵은 꼴 약 170KB라, 비트비트체가 더해지면 게임을 처음 열 때 받는 양이 몇 배로 는다. 받은 뒤에는 Cloudflare·브라우저 캐시를 쓴다.

## 4. 변경

| 위치 | 변경 |
|---|---|
| `games/fish-bun/assets/fonts/dnf-bitbit-v2/` | 넥슨 배포 TTF 원본 + 저작권 안내 |
| `games/fish-bun/src/index.ts` | 비트비트체를 갈무리11과 함께 불러오기 |
| `games/fish-bun/src/scene/ui.ts` | 제목 글꼴 이름과 `titleStyle(size, color)` |
| `screens.ts`, `DayView.ts`, `FishBunScene.ts` | §2의 글자를 `titleStyle`로, 가게 꾸리기 화면 출처 한 줄 |
| `docs/spec/fish-bun.md` | 글꼴 절 갱신, 출처 |

- 게임 로직·저장·서버는 바꾸지 않는다. 기존 테스트는 그대로 통과해야 한다.
- 메뉴 늘리기([261022-02](./261022-02-fish-bun-menu.md))·특별 손님([261022-03](./261022-03-fish-bun-special-customers.md))과 따로 만들 수 있다. 작아서 먼저 해도 된다.
