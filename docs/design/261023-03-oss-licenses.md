# 설계: 게임 설정의 오픈소스 라이선스 (붕어빵 가게·분식집)

상태: 컨펌, 구현함 (§7 구현 메모)

지금 붕어빵 가게·분식집의 **가게 꾸리기** 화면 맨 아래에 "글꼴: 던파 비트비트체 v2(넥슨), 갈무리11"이 늘 떠 있다.
강화를 고르는 화면에 출처가 떠 있어 어색하다. 다른 앱처럼 **설정 → 오픈소스 라이선스**에 모으고, 가게 꾸리기에서는 지운다.

---

## 1. 지금과 약관

| 쓰는 것 | 권리·라이선스 | 화면에 적어야 하나 |
|---|---|---|
| 던파 비트비트체 v2 (제목 글꼴) | 넥슨 서체 약관 (© NEOPLE) | 출처 표기 권장. 다른 소프트웨어에 번들할 때는 **저작권 안내를 함께 넣는다**는 조건(`assets/fonts/dnf-bitbit-v2/NOTICE.md`) |
| 갈무리11 (본문 글꼴) | OFL-1.1 (© Lee Minseo) | 글꼴과 함께 라이선스 글을 넣는다 |
| Phaser 4 (게임 엔진) | MIT (© Richard Davey, Phaser Studio Inc.) | 저작권·허가 문구를 함께 넣는다 |

지금은 글꼴 이름 한 줄만 있고 라이선스 글은 없다. 앱의 "오픈소스 라이선스"처럼 **목록 + 원문**을 두면 표기 위치도 자연스럽고 조건도 채운다.

---

## 2. 여는 곳

- 가게 화면 톱니(설정) 창에 **[오픈소스 라이선스]** 단추를 [닫기] 위에 하나 더한다(설정 창이 단추 하나만큼 길어진다).
- 멈춤 창에는 넣지 않는다(장사 중에 볼 일이 아니다).
- 가게 꾸리기 화면 맨 아래 글꼴 줄은 지운다. 게임 안 다른 곳에도 두지 않는다.

---

## 3. 화면

설정 창 위에 **화면 전체를 덮는 두 단계 화면**(목록 → 원문). 글이 길어 카드가 아니라 가게 꾸리기처럼 화면 전체를 쓴다.

```
[설정으로]   오픈소스 라이선스            [설정으로]   갈무리11
이 게임에 쓰인 글꼴과 라이브러리예요.     Lee Minseo · OFL-1.1
┌──────────────────────────┐          게임 안 글자
│ 던파 비트비트체 v2          │          https://galmuri.quiple.dev
│ 넥슨 · 넥슨 서체 약관       │          ─────────────────────
│ 제목·큰 숫자                │          Copyright © 2019–2025 ...
├──────────────────────────┤          This font software is ...
│ 갈무리11                    │          (원문, 휠·끌기로 스크롤)
│ Lee Minseo · OFL-1.1        │
│ 게임 안 글자                │
├──────────────────────────┤
│ Phaser                     │
│ Phaser Studio Inc. · MIT    │
│ 게임 엔진                   │
└──────────────────────────┘          [ 목록으로 ]
```

- **목록**: 항목마다 이름, 만든 곳 · 라이선스 이름, 쓰는 곳. 항목을 누르면 원문.
- **원문**: 이름, 만든 곳 · 라이선스, 쓰는 곳, 배포처 주소(글자로만, 누르지 않음), 그 아래 라이선스 원문. 원문은 휠·끌기로 스크롤(정산 화면과 같은 `scroll.ts`), 아래에 [목록으로] 고정.
  - 원문이 길어(OFL 약 95줄) 문단마다 글자 하나로 나눠 그린다(글자 텍스처가 너무 커지지 않게).
- 닫기: [설정으로]·Esc → 설정 창으로 돌아간다. 원문에서는 Esc·[목록으로] → 목록.
- 배치를 다시 그리면(회전 등) 보던 단계를 다시 연다.

### 3-1. 원문

| 항목 | 원문 출처 (고치지 않고 그대로) |
|---|---|
| 던파 비트비트체 v2 | 글꼴 안 저작권 표기 + 넥슨 서체 저작권 안내(지금 `NOTICE.md`에 옮겨 둔 문구) |
| 갈무리11 | npm `galmuri` 패키지의 `ofl.md` |
| Phaser | npm `phaser` 패키지의 `LICENSE.md` |

- 원문은 게임마다 `games/<id>/assets/licenses/`에 두고 번들러의 `?raw`로 가져온다. 두 게임은 서로 독립이라 각자 둔다(설정 창·스크롤처럼).
- 목록은 게임마다 `scene/licenses.ts` 한 곳. 게임이 새 글꼴·라이브러리를 쓰면 여기에 더한다.

---

## 4. 넣지 않는 것

- 사이트(셸)·미니게임이 쓰는 것(Vue, Pretendard 등)의 라이선스 목록. 셸에는 게임 안 설정 같은 자리가 없어 따로 정한다.
- 원문 안 주소를 눌러 여는 것(게임 캔버스 안이라 링크 대신 글자로 둔다).

---

## 5. 바뀌는 곳

| 위치 | 변경 |
|---|---|
| `games/fish-bun/src/scene/licenses.ts` (새) | 항목 목록과 목록·원문 화면 |
| `games/fish-bun/assets/licenses/` (새) | `dnf-bitbit-v2.md`, `galmuri-ofl.md`, `phaser-license.md` |
| `games/fish-bun/src/scene/settings.ts` | 설정 창 [오픈소스 라이선스] |
| `games/fish-bun/src/scene/FishBunScene.ts` | 라이선스 화면 열고 닫기, 다시 그릴 때 유지 |
| `games/fish-bun/src/scene/screens.ts` | 가게 꾸리기 글꼴 줄 삭제 |
| `games/snack-bar/...` | 같음 |
| `games/*/assets/fonts/dnf-bitbit-v2/NOTICE.md` | 출처 표기 위치를 "설정 → 오픈소스 라이선스"로 |
| 스펙 `fish-bun.md`, `snack-bar.md` | 설정 창·라이선스 화면, 출처 표기 줄 |

## 6. 확인

- 설정 → 오픈소스 라이선스 → 항목 → 원문 스크롤 → 목록으로 → 설정으로, 세로·가로.
- 가게 꾸리기 맨 아래 글꼴 줄이 없어졌는지.

---

## 7. 구현 메모

- 원문 파일 이름은 배포처 파일 형식대로 `.md`: `galmuri-ofl.md`(갈무리 `ofl.md` 그대로), `phaser-license.md`(Phaser `LICENSE.md` 그대로), `dnf-bitbit-v2.md`(글꼴 안 저작권 표기 세 줄 + `NOTICE.md`에 옮겨 둔 넥슨 서체 저작권 안내 + 배포처).
- 파일은 고치지 않고, 그릴 때만 마크다운 표시(`#` 제목, `&copy;`, `<주소>`)를 걷어 내고 문단 안 줄바꿈을 잇는다("- "로 시작하는 줄은 새 줄).
- 위 줄(제목·[설정으로]/[목록으로])은 바탕을 깔아 스크롤된 원문을 가린다. 원문 화면은 아래 [목록으로]도 고정으로 둔다.
- 배치를 다시 그리면(회전 등) 설정 창도 다시 연다(전에는 설정 창이 닫혔다). 라이선스 화면을 보고 있었으면 보던 단계까지.
