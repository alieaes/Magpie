# 설계: 분식집 — 도트 그림

[분식집](./261022-09-snack-bar.md)은 처음부터 **도트 그림**으로 만든다. 원작도 작은 도트 캐릭터가 가게를 뛰어다니는 게임이었다. 원작 그림은 쓰지 않고(CLAUDE.md §4-3) 새로 찍는다.
목표는 **귀여움**이다: 2등신 동물 직원과 손님, 통통 튀는 움직임, 따뜻한 색.

붕어빵 가게는 SVG 그림을 구운 뒤 도트로 바꿨다([261022-01](./261022-01-fish-bun-pixel-art.md)). 분식집은 캐릭터가 작고 많아서 **도트를 손으로 찍는 방식**을 쓴다(§5 대안 비교).

---

## 1. 방식: 코드 안의 도트 격자

그림 하나를 문자 격자로 적고, 글자마다 팔레트 색을 정한다. 게임을 열 때 이것을 텍스처로 굽는다.

```
// 예: 직원 머리(앞) 일부. '.'은 투명, 글자는 팔레트 색
const MAGPIE_HEAD_FRONT = [
  '....KKKKKK....',
  '...KKKKKKKK...',
  '..KKWKKKKWKK..',
  '..KKKKYYKKKK..',
  ...
];
```

| 항목 | 값 |
|---|---|
| 도트 한 칸 | 캔버스 4px(작은 아이콘·접시는 3px). 붕어빵 가게와 같은 밀도 |
| 팔레트 | 게임 전체 32색 하나. 그림 하나는 그중 16색 이하 |
| 테두리 | 굽는 단계에서 그림 바깥에 어두운 갈색 1칸을 자동으로 두른다(손으로 찍지 않아도 윤곽이 고르게) |
| 색 바꾸기 | 같은 격자에 색 표만 바꿔 다른 그림을 만든다(직원 두건 색, 손님 털 색, 깨끗한/더러운 테이블) |
| 확대 | 칸이 뭉개지지 않게 확대한다(붕어빵 가게와 같은 Phaser `smoothPixelArt`) |
| 위치 | `games/snack-bar/src/scene/sprites/` |

- 나중에 도트 도구로 직접 그린 PNG로 바꾸고 싶으면 같은 크기의 그림을 그대로 갈아 끼울 수 있게, 그림 이름과 크기를 한곳(`sprites/index.ts`)에 모은다.

## 2. 시점과 크기

- 시점은 **위에서 비스듬히 내려다보는 3/4 탑뷰**. 바닥은 위에서 보이고, 직원·손님·가구는 앞모습이 보인다(원작과 옛날 RPG 느낌).
- 격자 한 칸은 세로 화면 88px(22도트), 가로 화면 112px(28도트)다. 그림은 같은 텍스처를 쓰고 칸 가운데에 놓는다.

| 그림 | 크기(도트) | 장수 |
|---|---|---|
| 직원 몸(공통 틀) | 16 × 20 | 앞·뒤·옆 × 서기·걷기 = 6, 일하는 팔 3 |
| 직원 머리(직원마다) | 16 × 12 | 앞·뒤·옆 3장 × 9명 |
| 손님 앉은 몸(공통 틀) | 14 × 14 | 앞·뒤 2, 먹는 팔 2. 대식가는 통통한 틀 따로 |
| 손님 머리(종류마다) | 14 × 10 | 앞(활짝·보통·찡그림) 3 + 뒤 1 × 10종 |
| 테이블 · 의자 | 24 × 16 · 10 × 10 | 테이블 깨끗·더러움(빈 그릇·얼룩), 잠긴 테이블 천 |
| 조리대 | 24 × 24 | 떡볶이 철판, 김밥 도마, 순대 찜기, 라면 냄비, 튀김기, 물·단무지 통, 잠긴 덮개 |
| 음식 접시 | 10 × 8 (3px) | 메뉴 5, 물·단무지, 빈 그릇 |
| 바닥 · 벽 | 8 × 8 타일 | 체크무늬 바닥 두 색, 벽, 창문, 문, 메뉴판 |
| 아이콘 | 9 × 9 (3px) | 물컵, 하트, 분노 표시, 등급 별, 동전, 숟가락, 김 |

- 직원 = 공통 몸 위에 직원 머리를 겹친다. 9명이어도 몸은 한 벌이다. 옆모습은 좌우를 뒤집어 왼쪽·오른쪽에 쓴다.
- 손님은 직원과 겹치지 않는 동물 10종: 토끼, 양, 돼지, 오리, 개구리, 코알라, 펭귄, 다람쥐, 코끼리, 사슴. 털 색을 바꿔 같은 종류도 조금씩 다르게 보인다.
- 대식가는 통통한 몸 틀에, 머리 위 주문 표시에 그릇 수가 크게 붙는다.

## 3. 움직임 (귀여움 포인트)

| 때 | 연출 |
|---|---|
| 걷기 | 서기·걷기 두 장을 0.15초마다 번갈아, 몸 전체가 1칸 위아래로 통통 |
| 쟁반 들기 | 머리 위 쟁반에 접시가 칸 수만큼 올라가 보인다. 걸을 때 쟁반도 같이 흔들 |
| 연타 조리 | 일하는 팔 그림, 조리대에서 김·거품 도트가 튄다. 완성되면 반짝 십자 + 접시가 쟁반으로 폴짝 |
| 닦기 | 행주 팔이 좌우로, 다 닦으면 테이블에 반짝 |
| 손님 먹기 | 숟가락 팔 두 장 번갈아, 볼이 1칸 부풀었다 줄었다 |
| 기분 | 활짝이면 머리 위 하트가 떠오르고, 찡그리면 분노 표시가 깜빡, 화나서 나갈 때 김이 폭 |
| 계산 | 테이블 위로 동전이 튀어 오르고 받은 돈이 떠오른다 |
| 새 직원 | 문으로 걸어 들어와 꾸벅(머리 1칸 내림) → 폴짝 |
| 대기 | 서 있을 때 3초마다 눈 깜빡 |

- 연출은 화면(`scene`)만의 일이다. 로직 시간(걷기 9틱, 일 6틱)을 바꾸지 않는다.

## 4. 화면 그리기와 글꼴

- **화면 그리기**: 패널·버튼·말풍선은 계단형 모서리와 한 칸 테두리, 막대(하루 진행·기다림·조리 게이지)는 칸이 나뉜 각진 막대, 말풍선 꼬리는 계단 삼각형. 붕어빵 가게와 같은 규칙이지만 코드는 이 게임 안에 따로 둔다(게임끼리 독립, CLAUDE.md §4-3).
- **가게 실내**: 위쪽 벽에 메뉴판(메뉴 이름·값·등급 글자, 잠긴 메뉴는 가림), 창문 밖 하늘색이 시간에 따라 아침 → 노을 → 밤(8단 색 띠), 체크무늬 바닥, 문 위 종. 간판 "까치 분식"은 가게 화면(장사 전)의 가게 앞모습에 단다.
- **글꼴**: 게임 안 글자는 갈무리11 굵은 꼴(npm `galmuri`, 이 게임 패키지의 의존성), 제목·큰 숫자(간판, "N일째 아침", "마감!", 정산 제목, 레벨업)는 던파 비트비트체 v2. 붕어빵 가게와 같은 글꼴이라 두 게임의 분위기가 이어진다.
  - 던파 비트비트체 파일은 이 게임 폴더(`games/snack-bar/assets/fonts/dnf-bitbit-v2/`)에 **고치지 않고** 같은 파일과 `NOTICE.md`를 둔다. 내용이 같아 빌드 결과는 한 파일로 합쳐질 것으로 보고, 구현 때 확인한다.
  - 글자 크기는 11px 격자의 배수(최소 22px). 출처 표기는 가게 꾸리기 화면 맨 아래.
- **로비 카드**: 셸 화면이라 다른 카드처럼 매끈한 그림(떡볶이 접시를 든 까치 직원)으로 둔다.
- **개발용 그림 보기**: 개발 빌드에서 `?sprites`를 붙이면 모든 도트 그림(직원 9명의 걷기, 손님 10종 표정, 조리대, 접시)을 한 화면에 크게 늘어놓는다. 그림을 다듬을 때 쓴다. 배포 빌드에서는 빠진다.

## 5. 검토한 대안

| 대안 | 내용 | 판단 |
|---|---|---|
| SVG를 그려 도트로 굽기(붕어빵 가게 방식) | 이미 검증된 방식, 그림을 그리기 쉽다 | 16 × 20 같은 작은 캐릭터는 굽는 과정에서 눈·입이 뭉개져 귀여움이 살지 않는다. 직원 9명 × 3방향, 손님 10종을 색만 바꿔 늘리기도 어렵다 |
| PNG 스프라이트 시트 | 도트 도구로 그린 그림 파일 | 손으로 그리는 사람이 있으면 가장 예쁘다. 지금은 코드 격자로 찍고, 나중에 같은 크기 PNG로 갈아 끼울 수 있게 둔다(§1) |
| 사람 직원·손님 | 붕어빵 가게처럼 사람 | 2등신 동물이 도트에서 더 귀엽게 살고, 성별·나이를 한쪽으로 모는 문제도 없다. 동물로 간다 |
