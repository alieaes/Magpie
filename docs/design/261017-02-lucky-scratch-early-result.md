# 설계: 복권 긁기 — 다 긁기 전에 결과 내기

[복권 긁기](./261016-02-lucky-scratch.md)의 결과 판정을 바꾼다. 지금은 9칸이 다 드러나야(칸마다 절반쯤 긁혀 벗겨져야) 결과가 나온다.
같은 그림 3개가 이미 보이면 남은 칸과 상관없이 당첨이 정해지므로 그때 바로 결과를 내고,
모든 칸을 그림을 알아볼 만큼 긁었으면 덜 벗겨진 칸이 있어도 결과를 낸다(꽝 포함).

---

## 1. 바뀌는 것

| 경우 | 지금 | 바뀐 뒤 |
|---|---|---|
| 당첨 복권 | 9칸이 다 드러나면 결과 | **당첨 그림 3칸이 다 드러나는 순간** 결과, 또는 아래 꽝과 같은 기준 |
| 꽝 복권 | 9칸이 다 드러나면 결과 | **모든 칸이 30% 넘게 긁히면** 결과 (덜 벗겨진 칸이 남아도) |

- 30%는 붓으로 칸을 한 번 가로지르는 정도다(붓 한 줄이 칸의 약 38%를 덮는다). 그만큼이면 그림을 알아볼 수 있다. 튜닝값이다.
- 꽝을 그보다 일찍 알 수는 없다. 꽝 복권은 항상 같은 그림 쌍이 4개라서, 안 본 칸이 있는 동안은 3개가 될 가능성이 남아 있다.
- 결과를 낼 때 **남은 칸의 은박은 한 번에 벗긴다**(칸마다 빛이 번쩍, 부스러기, "샥" 소리 한 번). 당첨 칸 테두리·띠·동전 연출은 지금과 같다.
  은박을 남겨 두면 덜 긁힌 카드가 날아가서 어색하고, 나머지 그림을 보는 재미(아깝게 2개짜리 1등 그림 등)도 없어진다.
- "한 번에 긁기" 도중에 당첨 3칸이 드러나면, 그 자리에서 쓸기를 멈추고 결과를 낸다.

## 2. 바뀌지 않는 것

- 로직·서버: 입력 기록은 그대로 "긁기" 한 번이다. 재계산 점수와 서버 검사는 바뀌지 않는다.
- 긁기 간격 규칙(직전 긁기와 0.25초 이상)도 그대로다. 그보다 빨리 3칸이 드러나면 0.25초가 될 때까지 기다렸다 결과를 낸다(지금과 같은 방식).
- 칸이 벗겨지는 기준(절반쯤 긁히면 그 칸이 벗겨짐)도 그대로다.

## 3. 고칠 곳

- `games/lucky-scratch/src/scene/LotteryScene.ts`: 칸이 벗겨질 때 당첨 3칸이 다 드러났는지 보고 결과를 낸다. 결과를 낼 때 남은 칸을 벗긴다.
- 스펙 `docs/spec/lucky-scratch.md`의 긁기 항목.
