# 설계: 게임 방법 창 (붕어빵 가게·분식집)

상태: 컨펌, 구현함 (§8 구현 메모)

테스트해 보니 "언제 뒤집는지", "물을 어떻게 주는지"처럼 기본 조작을 모르는 사람이 있다.
두 성장형 게임에 **게임 방법** 창을 넣는다. 그림 한 줄 + 짧은 글 몇 줄을 한 쪽으로, 여러 쪽을 넘겨 본다.
게임 로직(`logic/`)은 건드리지 않는다.

---

## 1. 여는 곳

| 곳 | 어떻게 |
|---|---|
| 가게 화면 | 오른쪽 위 설정 단추 왼쪽에 **[게임 방법]** 글자 단추(높이는 설정 단추와 같게). "?" 하나만 두면 못 알아볼 수 있어 글자로 쓴다 |
| 멈춤 창 | 소리 줄과 [계속하기] 사이에 [게임 방법]. 장사 도중 막혔을 때 본다. 닫으면 멈춤 창으로 돌아오고, 시간은 계속 멈춰 있다 |
| 처음 하는 날 | 저장 상태가 **1일째**면 가게 화면에 들어올 때 한 번 저절로 연다(게임을 열 때마다 한 번. 다시 체험하기로 1일째로 돌아가도 그 판에서 또 열지 않는다). 따로 저장하지 않는다 |

장사 화면 시계 막대에는 단추를 더하지 않는다(멈춤 단추 → 멈춤 창으로 간다).

---

## 2. 창 모양

설정 창과 같은 틀: 화면을 어둡게 덮고 가운데 카드. 바깥을 누르거나 Esc면 닫힌다.

```
┌──────────────────────────────┐
│ 게임 방법               [닫기] │
│ 1. 굽기          ● ○ ○ ○ ○ ○ │  ← 쪽 제목, 쪽 점(눌러서 바로 가기)
│ ┌──────────────────────────┐ │
│ │   그림 (게임 그림 재사용)    │ │  ← 높이 약 240
│ └──────────────────────────┘ │
│ 빈 빵틀을 누르면 반죽을 부어요.  │
│ 김이 오르면 뒤집어요.          │  ← 꼭 알아야 할 줄은 강조색
│ 다시 김이 오르면 꺼내요.        │
│ ...                          │
│ [   이전   ]  [   다음   ]     │  ← 마지막 쪽은 [다음] 대신 [시작하기]/[닫기]
└──────────────────────────────┘
```

- 카드: 세로 배치 너비 = 화면 − 48, 높이 약 1000. 가로 배치 900 × 860.
- 글자: 갈무리11 굵은 꼴 24~26px, 한 쪽에 5줄 안팎. 넘치지 않게 글을 줄이는 것을 원칙으로 하고, 그래도 길면 글 부분만 스크롤(`scroll.ts`).
- 넘기기: [이전] [다음], 쪽 점 누르기, 카드를 좌우로 쓸기, 키보드 ← →.
- 마지막 쪽 단추: 가게 화면에서 연 경우 [닫기], 멈춤 창에서 연 경우 [멈춤 창으로].
- 그림은 게임에 이미 있는 텍스처를 쓴다(새 그림 없음). 쪽 사이에 화살표(→)로 순서를 보인다.
- 메뉴가 열리는 레벨 같은 숫자는 로직 표(`MENUS` 등)에서 가져와, 수치를 바꿔도 글이 낡지 않게 한다.

## 3. 붕어빵 가게 쪽 (6쪽)

| 쪽 | 그림 | 글 |
|---|---|---|
| 1. 굽기 | 빈 빵틀 → 반죽 → 뒤집은 빵 → 진열대 | 빈 빵틀을 누르면 반죽을 부어요(재료비). **김이 오르면 눌러서 뒤집어요.** **다시 김이 오르면 눌러서 꺼내요.** 연기가 나면 타는 중이에요. 누른 채로 빵틀 위를 쓸면 여러 칸을 한 번에 |
| 2. 익힘과 빵 값 | 덜 익음·알맞음·탐·황금 빵 4개, 아래 ×0.5 ×1 ×0.3 ×3 | 두 면 중 나쁜 쪽이 빵의 품질이에요. 꼬리가 다른 빵은 황금 후보: **반짝일 때 꺼내면 황금**, 놓치면 바로 타요 |
| 3. 화력 | 펌프·화력 계기 | 펌프를 누르고 있으면 화력이 오르고, 떼면 내려가요. 화력이 높으면 빨리 익지만 알맞은 때도 금방 지나가요. 계기의 ×숫자가 굽는 빠르기예요 |
| 4. 팔기 | 손님·말풍선·[N개 주기] [+1 덤] | 말풍선의 메뉴·개수대로 [N개 주기]. **[+1 덤]을 같이 주면 콤보**가 쌓여 보너스. 기다림 막대가 다 닳으면 떠나요. 진열대 왼쪽 빵부터 나가요. 탄 빵은 [탄 빵 버리기]. 메뉴가 여럿이면 위 반죽 단추로 골라 부어요 |
| 5. 손님 | 만난 손님 얼굴 | 지금 평판 레벨까지 오는 손님만 한 줄씩(꼬마: 덤을 좋아해요 / 직장인: 먼저 온 손님부터 / 어르신: 탄 빵 싫어함, 다 알맞으면 팁 / 수수께끼·관광객: [메뉴 고르기]로 맞혀요 / 먹방: 품질 상관없음 / 리뷰어: 평판 3배 / 진상: 화나면 빵틀을 깨요, 5번 눌러 고치기). 아직 안 온 손님은 "평판이 오르면 새 손님이 와요" 한 줄 |
| 6. 하루와 성장 | 가게 그림·평판 막대 | 하루는 3분(10:00~22:00), 마감 때 남은 빵은 버려져요. 하루 수익(매출 − 재료비)이 점수예요. 평판이 오르면 새 메뉴(Lv3 슈크림, Lv5 피자)와 손님. 번 돈으로 [가게 꾸리기] |

## 4. 분식집 쪽 (5쪽)

| 쪽 | 그림 | 글 |
|---|---|---|
| 1. 움직이기 | 직원과 노란 테두리 테이블 | 바닥을 누르면 걸어가요. **테이블·조리대를 누르면 앞까지 가서 바라봐요**(노란 테두리). **바라보는 채로 한 번 더 누르면 일해요.** 키보드: 방향키, 스페이스, 숫자 1~6(쟁반 칸), Esc |
| 2. 손님 한 테이블 | 물컵 말풍선 → 메뉴 말풍선 → 빈 그릇 → 더러운 테이블 | ① 앉으면 **물·단무지**: 물통에서 담고, 테이블을 바라보고 쟁반 칸을 눌러 줘요. ② **주문한 음식**을 같은 방법으로. ③ 다 먹으면 알아서 계산해요. ④ **더러운 테이블은 3번 닦아야** 다음 손님이 앉아요 |
| 3. 조리와 쟁반 | 조리대 → 쟁반 칸 | 메뉴 조리대를 여러 번 누르면 완성(첫 누름에 재료비). 완성되면 쟁반 빈 칸으로 가요. 쟁반이 가득하면 조리대에서 기다려요(초록 깜빡). 안 시킨 음식은 받지 않아요. 남는 건 쓰레기통을 바라보고 쟁반 칸을 눌러 버려요 |
| 4. 손님 기분 | 활짝·보통·찡그림 얼굴, 기다림 막대 | 물·음식을 기다리는 동안 막대가 줄고, 다 닳으면 기분이 한 칸 나빠져요(막대는 다시 차요). 기분이 바닥(-3)이면 화나서 돈을 안 내고 나가요. 물·음식·계산마다 기분이 좋아지고, 기분이 좋으면 팁. 깨끗한 빈 테이블이 없으면 손님이 돌아가요 |
| 5. 하루와 성장 | 가게 앞모습·메뉴 아이콘 | 하루는 4분(09:00~21:00). 21:00 뒤 남은 테이블을 치우면 마감. 가게 Lv이 오르면 새 메뉴(Lv2 순대, Lv4 라면, Lv6 튀김)와 강화. 많이 판 메뉴는 등급이 올라 값이 올라요. 조건을 채우면 새 직원 — 직원 명부에서 오늘의 직원을 골라요 |

글은 위 내용을 기준으로 구현하면서 줄 길이에 맞춰 다듬는다(뜻은 바꾸지 않는다).

## 5. 넣지 않는 것

- 장사 중 상황 안내(예: 1일째 첫 빵이 익으면 빵틀 위에 "지금 뒤집어요!"). 효과는 크지만 장사 화면을 고쳐야 하는 다른 기능이라 따로 설계한다.
- 따라 하기 튜토리얼(한 단계씩 시키는 연습 판).
- 셸(Vue) 쪽 설명 페이지. 게임 화면 안에서만 본다.

## 6. 바뀌는 곳

두 게임은 서로 독립이라(CLAUDE.md §4-3) 설정 창·스크롤처럼 게임마다 따로 둔다.

| 위치 | 변경 |

| `games/fish-bun/src/scene/guide.ts` (새) | 쪽 내용(그림·글)과 `buildGuidePanel` |
| `games/fish-bun/src/scene/screens.ts` | 가게 화면 [게임 방법] 단추(`onGuide`) |
| `games/fish-bun/src/scene/FishBunScene.ts` | 창 열고 닫기, 1일째 저절로 열기, 멈춤 창 [게임 방법] |
| `games/snack-bar/src/scene/guide.ts` (새) | 같음 |
| `games/snack-bar/src/scene/screens.ts`, `SnackBarScene.ts` | 같음. 창이 열린 동안 장사 키보드 조작은 받지 않는다 |
| `docs/spec/fish-bun.md`, `docs/spec/snack-bar.md` | 화면 절에 게임 방법 창 |

## 7. 확인

- 세로(720 × 1240·1640)·가로(1560 × 1000)에서 쪽마다 글이 카드 안에 들어오는지.
- 멈춤 창에서 열고 닫은 뒤 시간이 흐르지 않았는지, 계속하기가 되는지.
- 1일째 가게 화면에서 한 번만 저절로 열리는지.

## 8. 구현 메모

- 카드 크기: 높이를 쪽마다 바꾸지 않고 **가장 긴 쪽(그림 + 글)에 맞춘다**(화면 - 48까지). 세로 배치에서 아래가 크게 비던 것을 없앴고, 글 스크롤은 넣지 않았다(평판 Lv5 손님 9줄도 세로 1240에 들어간다). 가로 배치 너비는 1000.
- 붕어빵 손님 쪽은 그림 칸을 140으로 줄이고 손님 얼굴을 한 줄로, 글 줄 앞에는 장사 화면과 같은 성격 아이콘(`DayView`의 `TRAIT_ICON`을 내보내 같이 쓴다)을 둔다.
- 붕어빵 굽기 쪽 그림 칸은 빵틀 판 색 바탕이라 흰 김이 보인다. 김 나는 단계 글자는 노란색.
- 분식집 [계속하기]는 멈춘 동안 누른 키(게임 방법 창의 ← → 등)가 다시 이어서 걷지 않게 미뤄 둔 조작을 버린다(`releaseAll`). 붕어빵 가게는 키보드 조작이 없어 그대로.
- 분식집 손님 기분 쪽은 표정이 잘 보이는 돼지 손님(생김새 2)을 쓴다.
