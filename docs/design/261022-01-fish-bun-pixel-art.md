# 설계: 붕어빵 가게 — 도트 그림

[붕어빵 가게](./261021-01-fish-bun.md)를 원작(피처폰 붕어빵타이쿤3)처럼 **도트 느낌**으로 바꾼다. 지금은 매끈한 SVG 그림이라 원작의 분위기가 사라졌다.
원작의 도트 그림 자체는 쓸 수 없으므로(CLAUDE.md §4-3), **우리 그림을 도트로 굽는다.** 게임 규칙·배치·저장은 바꾸지 않는다.

---

## 1. 방식

### 1-1. 그림 도트 굽기

지금 SVG 그림을 그대로 두고, 텍스처를 구울 때 도트로 바꾼다.

```
SVG → 1/4 크기로 굽기 → 투명도 딱 자르기 → 색 수 줄이기 → 바깥 1칸 어두운 테두리 → 4배 확대(뭉개지 않게)
```

| 항목 | 값 |
|---|---|
| 도트 한 칸 | 캔버스 4px. 세로 화면(720px) 기준 가로 180칸 — 원작 240 × 320 화면과 비슷한 밀도 |
| 투명도 | 반투명 가장자리를 없앤다(완전 투명 / 불투명 둘 중 하나) |
| 색 | 그림 하나에 많이 쓰인 색 16개까지. 비슷한 색은 합친다 |
| 테두리 | 그림 바깥에 어두운 갈색(#2a1a10) 1칸. 피처폰 게임 그림처럼 윤곽이 또렷해진다 |
| 대상 | 붕어빵(익힘 단계별), 빵틀, 진열대 아이콘, 손님 6종 × 2 × 3, 펌프, 아이콘, 동전, 간판 까치 |

미리보기(같은 그림을 변환만 한 것): 붕어빵·황금붕어빵·빵틀·손님이 1칸 테두리와 계단 윤곽을 가진 도트가 된다.
색이 서서히 바뀌는 익힘 연출(두 그림을 섞기)은 그대로 쓴다.

### 1-2. 화면도 도트로

그림만 도트이고 나머지가 매끈하면 어색하다. 장면에서 직접 그리는 것도 맞춘다.

| 부분 | 지금 | 바꾸면 |
|---|---|---|
| 확대 | 부드럽게 늘림 | Phaser `pixelArt: true` — 캔버스를 키워도 칸이 뭉개지지 않는다 |
| 패널·버튼·말풍선 | 둥근 모서리 | 계단형 모서리(4px 단위)와 2칸 테두리 |
| 하늘 | 매끈한 그라데이션 | 6~8단 색 띠 |
| 차양 물결, 김·연기·반짝이 | 원·부드러운 점 | 도트 조각 그림 |
| 진행 막대·화력 계기·기다림 막대 | 둥근 막대 | 칸이 나뉜 막대 |

### 1-3. 글꼴

- **게임 안 글자만** 한글 도트 글꼴 **갈무리11**(Galmuri11, OFL-1.1, quiple)로 바꾼다. 상단 바 등 셸 화면은 Pretendard 그대로다.
- npm 패키지(`galmuri`)에서 Galmuri11 woff2 한 파일(보통·굵게)만 게임 번들에 넣어 자체 호스팅한다. 이 게임을 열 때만 내려받는다.
- 글자 크기는 글꼴 격자(11px)의 배수(22·33·44px)로 맞춰 획이 또렷하게 한다. 지금 크기에서 가장 가까운 배수로 바꾼다.

### 1-4. 로비 카드

로비 카드 그림(`GameThumb.vue`)은 다른 게임 카드와 같은 매끈한 그림이다. 이번에는 그대로 둔다(셸 화면이라서).

## 2. 검토한 대안

| 대안 | 내용 | 판단 |
|---|---|---|
| 손으로 찍은 도트 | 그림마다 픽셀을 직접 찍는다 | 원작에 가장 가깝지만 그림 양(손님만 36장)이 많다. 1-1로 먼저 바꾸고, 자주 보이는 붕어빵·빵틀만 나중에 손으로 다듬을 수 있다 |
| 화면 전체를 낮은 해상도로 그리기 | 캔버스를 180 × 350으로 그리고 키운다 | 가장 확실한 도트지만 지금 글자 크기로는 한글이 읽히지 않는다. 배치를 모두 다시 해야 한다 |
| 그림만 도트 | 1-1만 한다 | 패널·글자가 매끈해서 섞여 보인다 |

## 5. 구현 메모 (2026-10-22)

설계대로 만들었고, 설계에 적지 않았던 세부를 아래처럼 정했다. 확정 규칙은 [스펙 fish-bun.md](../spec/fish-bun.md) "도트 그림체".

- **그림체 설정은 `scene/style.ts`의 `ART_STYLE`** 하나다. `'smooth'`면 그림·글꼴·모서리·하늘·막대가 모두 바꾸기 전으로 돌아간다. 도트로 바꾸기 전 커밋(4391bb9)에 태그 `fish-bun-svg-art`를 남겼다(로컬 태그, 원격에 올리지 않음).
- **칸 크기는 그림의 보이는 크기에 맞춰 둘로 나눴다.** 붕어빵·빵틀·손님·펌프는 4px, 작게 보이는 진열대 아이콘·아이콘·동전·간판 까치는 3px(4px면 모양이 뭉개졌다).
- **확대는 Phaser `smoothPixelArt`로 했다.** 완전한 최근접 확대(`pixelArt`)는 빵틀처럼 1.33배 같은 소수 배율에서 칸 굵기가 들쭉날쭉해서, 칸은 유지하고 경계만 부드럽게 하는 쪽을 골랐다.
- **글꼴은 굵은 꼴 한 파일만 쓴다.** 갈무리11 보통 꼴은 505KB, 굵은 꼴은 167KB이고 둘 다 한글 11,172자를 다 가진다. 게임에서 쓰는 글자를 모두 대조했고, 굵은 꼴에 없는 "−"(빼기 기호)만 "-"로 바꿨다.
- **글자 크기는 11px 격자의 배수, 최소 22px.** 휴대폰에서는 캔버스가 절반쯤으로 줄어 11px이면 읽히지 않는다. 크기가 바뀌면서 겹친 곳(간판의 까치와 가게 이름, 펌프 글자, 화구 효과 글)을 다시 놓았다.
- 화면 검증: 가로·세로 배치에서 가게 화면, 장사 화면(붓기·뒤집기·김·연기·손님·말풍선·버튼·막대), 가게 꾸리기 화면을 확인했다. 게임 로직은 바꾸지 않았고 테스트는 그대로 통과한다.
