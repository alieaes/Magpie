# 붕어빵 "지금 뒤집어요/꺼내요" 신호 강화

상태: 제안 (유저 컨펌 대기)

## 1. 지금

빵이 알맞게 익는 구간(`doneAt` ~ `burnAt`)에는 22프레임(약 0.37초)에 한 번 김이 한 알 올라온다.
이 김이 뒤집을 때·꺼낼 때를 알려 주는 유일한 신호인데 약하고, 구간에 들어서는 순간을 짚어 주지 않는다.
(황금 후보는 금빛으로 깜박이는 따로의 신호가 있어 이 안의 대상이 아니다.)

## 2. 안 (세 가지를 함께, 모두 작게)

1. **들어서는 순간 한 번 "퐁"**: 구간에 들어서는 프레임에 김을 4~5알 한꺼번에 내보낸다. "방금 익었다"를 알려 준다.
2. **익은 동안은 김이 더 촘촘히**: 간격 22프레임 → 12프레임, 김 알 크기·불투명도를 조금 키운다. 타기 시작(`burnAt`)하면 지금처럼 회색 연기로 바뀌어 대비가 난다.
3. **빵이 살짝 숨 쉬듯 부푼다**: 구간 동안 빵 크기가 1.0 ↔ 1.04를 천천히 오간다. 김을 못 봐도 모양으로 알아챈다.

넣지 않는 것: 빵 테두리 빛나기(황금 후보의 금빛 신호와 헷갈린다), 새 소리(소리를 끄고 하는 사람은 못 듣고, 틀마다 울리면 시끄럽다).

색은 흰 김 그대로라 "타는 중"의 회색 연기와 구분된다. 도트 모드(`PIXEL_ART`)에서도 같은 크기 규칙을 쓴다.

## 3. 바뀌는 곳

`games/fish-bun/src/scene/DayView.ts` — 빵틀 그리기 갱신(김 간격·구간 진입 감지)과 `buildParticles`의 김 설정.
구간 진입은 틀 화면(`MoldView`)에 이전 프레임의 `puff` 값을 기억해 감지한다. 게임 로직(`logic/`)은 건드리지 않는다.
스펙 `fish-bun.md`의 연출 설명 갱신.
