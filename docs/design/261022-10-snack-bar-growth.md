# 설계: 분식집 — 성장(돈·경험치·메뉴 등급·강화)

[분식집](./261022-09-snack-bar.md)에서 하루 장사 사이에 남는 것들: 돈, 경험치와 가게 레벨, 메뉴 등급, 강화, 정산.
원작의 성장은 메뉴 등급과 레벨뿐이었고 나머지(재료 구매·아이템)는 서버에 있어서 남아 있지 않다. 그래서 붕어빵 가게처럼 **번 돈으로 가게를 키우는 강화**를 더한다.
캐릭터 해금은 [261022-11](./261022-11-snack-bar-characters.md), 저장과 검증은 성장형 공통([saves.md](../spec/saves.md))을 그대로 쓴다.

---

## 1. 시작 상태

| 항목 | 값 |
|---|---|
| 날짜 | 1일째 |
| 돈 | 5,000원 |
| 경험치 | 0, 가게 Lv1 |
| 메뉴 | 떡볶이·김밥, 둘 다 E등급 |
| 테이블 | 4개 |
| 쟁반 | 3칸 |
| 걸음 | 한 칸 9틱(0.15초) |
| 직원 | 까치 사장([261022-11](./261022-11-snack-bar-characters.md)) |

- **하루 시작 지원금**: 하루를 열 때 돈이 3,000원 미만이면 3,000원으로 채운다. 재료비가 없어 장사를 못 하는 상태를 막는다(붕어빵 가게와 같은 장치). 정산에 "운영 지원금"으로 보여 준다.

---

## 2. 경험치와 가게 레벨

- 하루 경험치 = **판 그릇 수 + 손님 서비스 점수의 합**(원작 규칙). 서비스 점수는 손님이 나갈 때의 기분 점수(−3 ~ +3, [261022-09 §5-3](./261022-09-snack-bar.md)).
- 하루 경험치가 음수면 0으로 친다. **경험치와 레벨은 내려가지 않는다.**
- 레벨 L이 되는 누적 경험치 = **50 × L × (L − 1)** (원작 공식).

| 레벨 | 누적 경험치 | 열리는 것 |
|---|---|---|
| Lv1 | 0 | 떡볶이·김밥, 테이블 4개 |
| Lv2 | 100 | 순대, 대식가 손님 |
| Lv3 | 300 | 테이블 늘리기 1단계, 센 불 1단계 |
| Lv4 | 600 | 라면, 큰 쟁반 2단계 |
| Lv5 | 1,000 | 테이블 늘리기 2단계 |
| Lv6 | 1,500 | 튀김, 센 불 2단계 |
| Lv7 이상 | 2,100, 2,800, 3,600, 4,500 … | 손님 표는 Lv6과 같다. 캐릭터 해금 조건에 쓴다 |

- 하루 손님 25명 안팎, 평균 서비스 점수 +2면 하루 경험치 70~80쯤이다. 2일째에 Lv2, 2주 안팎에 Lv6을 목표로 한다(§6).
- 레벨에 따른 손님 간격·두 명 비율·대식가 비율은 [261022-09 §5-4](./261022-09-snack-bar.md).

## 3. 메뉴 등급

원작의 핵심 성장. 메뉴마다 **누적 판매 그릇 수**로 등급이 오른다. 많이 판 메뉴일수록 맛이 좋아져 손님이 더 자주 찾고 값도 오른다.

| 등급 | 누적 판매 | 값 배율 | 주문 비중 |
|---|---|---|---|
| E | 0 | 100% | 3 |
| D | 30그릇 | 110% | 4 |
| C | 90 | 120% | 5 |
| B | 200 | 130% | 6 |
| A | 400 | 140% | 7 |
| S | 800 | 150% | 8 |

- 원작은 주문 비중이 등급 그대로(E=1 … )라서 나중에 열린 메뉴가 거의 주문되지 않는다. 비중에 2를 더해 새 메뉴도 주문이 들어오게 한다(튜닝값).
- 그날의 등급은 아침 기준이다. 하루 도중에 기준을 넘어도 다음 날부터 바뀐다.
- 화면: 조리대 옆 등급 글자, 정산에 "떡볶이 D → C까지 12그릇", 등급이 오르면 정산에서 글자가 반짝인다.

## 4. 강화 (가게 꾸리기)

"가게 꾸리기" 화면에서 산다. 사는 즉시 저장된다(가게 행동 `{ op: 'upgrade', key }`). 되돌릴 수 없다.

| key | 이름 | 단계 | 효과 | 비용(안) | 열리는 조건 |
|---|---|---|---|---|---|
| `tables` | 테이블 늘리기 | 2 | 4 → 5 → 6개(T1, T4가 열림) | 20,000 / 60,000 | Lv3 / Lv5 |
| `tray` | 큰 쟁반 | 2 | 3 → 4 → 5칸 | 15,000 / 45,000 | — / Lv4 |
| `shoes` | 운동화 | 4 | 걸음 9 → 8 → 7 → 6 → 5틱 | 10,000부터 2배 | — |
| `stove` | 센 불 | 2 | 모든 메뉴 연타 −1 | 30,000 / 90,000 | Lv3 / Lv6 |
| `jug` | 큰 물통 | 1 | 물·단무지를 한 번에 2세트 | 12,000 | — |
| `interior` | 인테리어 | 5 | 손님 기다림 막대 +8%/단계 | 8,000부터 2배 | — |
| `sign` | 간판 | 5 | 손님 무리 간격 −8%/단계(최소 4초) | 10,000부터 2배 | — |

- 캐릭터 능력과 겹치면 더한다. 다만 쟁반은 최대 6칸, 걸음은 최소 4틱, 연타는 최소 2번, 물·단무지는 최대 3세트다.
- 실패 사유: `max_level`, `locked`(레벨 부족), `no_money`.
- 화면은 붕어빵 가게와 같은 카드식: 그림, 이름, 단계 점, 지금 → 다음 효과, 비용 버튼, 조건이 안 되면 "Lv3부터". 사면 가게 그림에 바로 반영한다(테이블 천이 걷히고, 쟁반이 커지고, 간판이 바뀐다).
- 비용·효과는 튜닝값이다. §6 시뮬레이션으로 맞춘다.

## 5. 정산

하루가 끝나면 보여 준다. 숫자는 서버가 같은 로직으로 다시 계산한 값과 같아야 저장된다.

```
3일째 장사 끝
  음식 값           46,500원
  팁                 3,200원
  재료비           −15,400원   (22그릇)
  ─────────────────────────
  하루 수익          34,300원   ← 랭킹 점수
  버린 접시              1개
  손님 24명   활짝 15(최고 9) · 보통 6 · 찡그림 1 · 화나서 나감 2
  자리가 없어 돌아감 1무리
  메뉴  떡볶이 11그릇 (D → C까지 12) · 김밥 9 · 순대 2
  경험치 +68   Lv2 → Lv3   새로 열림: 테이블 늘리기, 센 불
  새 직원이 왔어요!  강아지
  [가게 꾸리기]   [직원 고르기]   [다음 날 장사]
```

- 하루 수익 = 음식 값 + 팁 − 재료비. 0 미만이면 랭킹 점수는 0이다(돈은 실제로 줄어든다). 화나서 나간 손님에게 낸 음식, 버린 접시의 재료비도 재료비에 들어 있다.
- 레벨이 오르면 새 메뉴·새 손님·새로 열린 강화를, 캐릭터가 열리면 새 직원을 알려 준다([261022-11 §4](./261022-11-snack-bar-characters.md)).
- 저장 상태 줄과 버튼은 붕어빵 가게와 같다("저장했어요 · 최고 수익 · 전체 N위", 저장 실패면 [다시 보내기], 체험이면 로그인 안내).

### 5-1. 저장 상태 (v1)

| 항목 | 내용 |
|---|---|
| `day`, `money`, `exp` | 일수, 돈, 누적 경험치 |
| `sold` | 메뉴별 누적 판매 그릇 수(메뉴 등급의 근거) |
| `upgrades` | 강화 7종 단계 |
| `character`, `unlocked` | 오늘의 직원, 열린 직원 목록([261022-11](./261022-11-snack-bar-characters.md)) |
| `stats` | 누적 손님·기분 최고(+3) 손님·화나서 나감·물 낸 횟수·닦은 테이블·대식가 무리·누적 매출, 최고 하루 수익 |

- 메뉴 열림과 등급은 `exp`, `sold`에서 계산하므로 따로 저장하지 않는다.

## 6. 밸런스 목표

| 시점 | 목표 |
|---|---|
| 1일째 | 하루 수익 20,000~30,000원, 첫 강화 하나를 살 수 있다 |
| 2일째 | Lv2(순대), 첫 새 직원 |
| 5일째 무렵 | 테이블 5개 |
| 2주 무렵 | Lv6, 메뉴 5개, 테이블 6개 |
| 30일째 무렵 | 강화 대부분, 직원 6~7명 |

- 로직 테스트에 **흉내 플레이어**를 둔다: 정해진 실력(초당 누르는 수, 일 고르는 순서: 물 → 음식 → 조리 → 닦기)으로 하루를 돌리는 스크립트. 여러 시드로 1~30일을 돌려 위 목표에 맞게 값을 고친다(붕어빵 가게와 같은 방식).
- 하루에 다 받을 수 있는 손님보다 조금 더 오게 해서, 테이블·쟁반·걸음 강화가 바로 수익으로 이어지게 한다.

---

## 7. 테스트

- 레벨: 공식대로 오른다, 하루 경험치가 음수면 0, 레벨에 따라 메뉴·손님 표가 열린다.
- 메뉴 등급: 기준 그릇 수에서 오른다, 아침 기준으로 하루 동안 고정, 값 배율과 주문 비중이 표대로.
- 강화: 돈 부족·조건 미달·최대 단계는 실패, 성공하면 돈이 줄고 단계가 오르고 다음 날 효과가 적용된다. 캐릭터 능력과 겹칠 때 최댓값·최솟값.
- 지원금: 하루를 열 때 3,000원 미만이면 3,000원.
- 정산: 음식 값 + 팁 − 재료비 = 하루 수익, 음수면 랭킹 점수 0.

- [ ] 강화 7종(§4). 수치는 시뮬레이션으로 조정
- [ ] 하루 시작 지원금 3,000원
