# 체험한 하루를 계정에 저장하기

상태: 제안 (유저 컨펌 대기)

## 1. 문제

성장형 게임(붕어빵 가게)은 로그인 전에 하루를 체험해 볼 수 있다. 정산 화면에서 [로그인하고 저장하기]를 눌러 로그인하면,
체험은 브라우저 메모리에만 있어서 사라지고 가게는 1일째 아침부터 다시 시작한다. 방금 한 하루가 헛수고가 된다.

## 2. 목표

로그인(닉네임 포함)한 뒤 가게를 열었을 때, 이 계정에 **플레이 기록이 없으면** 방금 체험한 하루를 계정의 첫 하루로 저장한다.

- 기록이 없다 = 저장 버전이 1(시작 상태 그대로)이고 통과한 판이 하나도 없다.
- 기록이 있으면 체험은 버린다(이미 키우는 가게를 덮어쓰지 않는다).

## 3. 흐름

1. 체험 하루가 끝나면 체험 창구(`createTrialSession`)가 `{ seed, inputs, ticks, score }`를 `localStorage`(`magpie.trialDay.<gameId>`)에 적는다.
   로그인은 Google 화면을 거쳐 페이지가 새로 뜨므로 메모리가 아니라 저장소에 둬야 한다. 다시 체험하면 마지막 것으로 덮어쓴다. 개발용 `?seed=` 체험은 적지 않는다.
2. 로그인 후 `createSavedSession.load()`가 저장을 불러온다. 저장 버전이 1이고 적어 둔 체험 하루가 있으면 서버에 올린다.
3. 서버가 시작 상태로 그 하루를 다시 돌려 검증하고, 통과하면 다음 날 상태를 저장한다(버전 2). 응답의 저장으로 가게가 열린다.
4. 서버가 판정을 내리면(통과·거절·4xx) 적어 둔 체험 하루를 지운다. 연결 실패·5xx면 남겨 두고 다음에 다시 시도한다.
   저장 버전이 1이 아니면 올리지 않고 바로 지운다.

## 4. 서버

`POST /api/plays/adopt-trial` — 본문 `{ gameId, seed, inputs, ticks, score }`, 응답 `{ adopted: true, save } | { adopted: false, reason }`.

검사:

1. 로그인 + 닉네임, 성장형 게임.
2. 저장이 시작 상태 그대로(버전 1)이고 이 게임의 통과한 판이 없다. 아니면 `reason: 'has_record'`.
3. `replayDay(seed, inputs, initialState)`로 다시 돌려 점수·틱이 맞는지 확인(기존 재계산 자리 `ReplayRunner` 그대로).
   경과 시간 검사는 없다(서버가 연 판이 아니라서 시작 시각이 없다). `ticks ≤ maxTicks`만 본다.
4. 한 트랜잭션에서 저장 줄을 잠그고 버전을 다시 확인한 뒤, 판(통과)·입력 기록을 남기고 저장을 `nextState`로 바꾼다(버전 +1).

### 랭킹에는 넣지 않는다

체험은 시드를 클라이언트가 정한다. 이 점수를 랭킹에 올리면 유리한 손님 순서가 나오는 시드를 미리 찾아 올릴 수 있다.
그래서 체험 하루는 **가게 상태(돈·평판·통계)로만** 이어받고 최고 기록(`updateBests`)은 갱신하지 않는다.
시드를 마음대로 고르는 것으로 얻는 것은 시작 때 돈 약간이 전부이고, 계정당 한 번뿐이다.
랭킹은 로그인 후 서버가 시드를 주는 하루부터 쌓인다.

## 5. 바뀌는 곳

| 곳 | 내용 |
|---|---|
| `client/src/games/growthSession.ts` | 체험 하루 적기·읽기·지우기, `load()`에서 올리기 |
| `client/src/api.ts` | `adoptTrialDay` |
| `server/src/plays/` | 체험 하루 받는 함수(서비스) + 라우트 |
| `shared/src/` | 요청·응답 형식 |
| 테스트 | 통과 / 이미 기록 있음 / 조작된 입력 거절 / 재시도(동시 두 번) |
| 스펙 | `saves.md`, `plays.md` |

게임 코드(`games/fish-bun`)는 건드리지 않는다. 창구가 `load()`에서 알아서 처리해 게임은 평소처럼 저장을 받는다.

## 6. 하지 않는 것

- 체험 중 강화 구매 같은 것은 원래 막혀 있어서 옮길 것이 없다(하루 결과뿐).
- "체험한 하루가 저장됐어요" 같은 안내는 넣지 않는다. 필요하면 따로 얹는다.
