# 붕어빵 화력 계기 문구 고정

상태: 제안 (유저 컨펌 대기)

## 1. 문제

화력 계기 글자가 칸 너비에 따라 `화력 50% · 속도 ×1.1` / `화력 50% · ×1.1` / `50% · ×1.1` 세 가지로 바뀐다.
화면 비율이 바뀌거나 숫자 자릿수가 달라질 때 문구 모양이 오락가락해 시선이 뺏긴다.

## 2. 안

문구를 `×1.6` 하나로 고정한다. 화력 퍼센트는 계기 막대와 색(파랑·주황·빨강)이 이미 보여 주므로 글자에서 뺀다.

- 글자 길이가 늘 거의 같아(`×0.6` ~ `×1.6`) 칸에 맞춰 줄이는 처리가 필요 없다. `heatKey`·너비 비교 반복을 걷어 낸다.
- 숫자가 바뀔 때만 글자를 다시 쓴다(지금과 같다).

## 3. 바뀌는 곳

`games/fish-bun/src/scene/DayView.ts`의 계기 갱신 부분(`heatText`), 스펙 `fish-bun.md`의 화력 계기 설명.
