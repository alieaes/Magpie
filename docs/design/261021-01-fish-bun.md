# 설계: 붕어빵 가게 (`fish-bun`) — 핵심 플레이

붕어빵을 구워 팔면서 가게를 키우는 게임. 2006년 피처폰 게임 「붕어빵타이쿤3」(컴투스)의 메커니즘(반죽 붓기 → 뒤집기 → 꺼내기, 손님 성격, 덤과 콤보)을 빌려 온다.
Magpie의 다른 게임과 달리 **1~5분짜리 한 판으로 끝나지 않는다.** 하루 장사를 마칠 때마다 저장하고, 번 돈으로 가게를 강화해 다음 날 이어서 한다(성장형).

원작의 이름·캐릭터·그림·소리·대사는 쓰지 않는다(CLAUDE.md §4-3). 게임 이름은 **"붕어빵 가게"**, 게임 안 가게 간판은 **"까치 붕어빵"** 으로 한다
(복권 긁기의 "까치 즉석복권"과 같은 자체 브랜드).

## 1. 원작에서 바꾸는 점

| 원작 (피처폰, 240×320, 키패드) | 붕어빵 가게 (터치 스마트폰·PC) |
|---|---|
| 굽는 화면과 파는 화면을 ▲ 키로 오간다 | **한 화면**에 손님 카운터·진열대·빵틀을 같이 둔다 |
| 숫자키 1~9, \*, 0, #으로 빵틀 12칸을 누른다 | 빵틀을 **직접 탭**한다. 쓸어 넘기면 여러 칸을 한 번에 |
| 확인(OK) 키 연타로 펌프질 | 펌프 버튼을 **누르고 있으면** 화력이 오른다 |
| ◀▶로 손님을 고르고 1~3키로 개수를 정한다 | 손님 아래 **[N개 주기] [+1 덤]** 버튼 |
| 고양이가 올라와 펫에 닿으면 게임 오버 | 게임 오버 없음. **하루 영업 시간**이 끝나면 정산 |
| 한 판 끝나면 점수만 남는다 | 하루마다 **저장**, 번 돈으로 **강화**, 다음 날 이어서 |
| 노멀·버닝·러쉬 3모드 | 하루 장사 하나. 버닝·러쉬는 뺀다(§7) |
| "1개 싸줘잉~" 같은 2000년대 말투 | 요즘 말투로 새로 쓴다([261021-02](./261021-02-fish-bun-customers.md)) |

## 2. 하루 장사

```
가게 화면 (3일째 · 12,340원 · 평판 Lv3)
  → [장사 시작]
  → 하루 영업 3분 (게임 시계 10:00 → 22:00)
  → 마감 → 정산 → 가게 꾸리기(강화) → [다음 날 장사]
```

| 항목 | 값 |
|---|---|
| 하루 길이 | 실제 3분 = 10,800틱. 게임 시계 1분 = 15틱 |
| 실패 | 없다. 손님을 놓치거나 빵을 태우면 돈과 평판만 덜 오른다 |
| 마감 직전 | 21:30(마감 30초 전)부터 새 손님이 오지 않는다. 상단 시계가 주황색이 된다 |
| 마감 | 카운터에 남은 손님은 그냥 떠난다(평판 변화 없음). 진열대·빵틀에 남은 빵은 **폐기**하고 정산표에 적는다 |
| 일시정지 | 언제든 할 수 있다. 화면이 가려지면 자동으로 멈춘다(미니게임처럼 판을 끝내지 않는다) |
| 중간에 나가기 | 그날 장사는 저장되지 않는다. 다시 오면 **그날 아침부터** 다시 한다(저장 단위가 하루라서, [261021-04](./261021-04-game-save.md)) |

## 3. 굽기

### 3-1. 빵틀 상태

빵틀 한 칸을 탭할 때마다 "다음 동작"을 한다. 빈 틀이면 붓고, 굽는 중이면 뒤집고, 뒤집은 뒤면 꺼낸다.

```
빈 틀 --탭--> 아랫면 굽는 중 --탭--> 윗면 굽는 중 --탭--> 꺼냄(진열대로)
       붓기   (덜 → 알맞음 → 탐)  뒤집기 (덜 → 알맞음 → 탐)  꺼내기
```

| 상태 | 화면 | 탭하면 |
|---|---|---|
| 빈 틀 | 빈 무쇠 틀 | 반죽을 붓는다. **재료비 50원**을 바로 낸다. 돈이 모자라면 부을 수 없다 |
| 아랫면 굽는 중 | 위에서 본 반죽 + 가운데 팥. 익을수록 테두리가 노릇해지고, 너무 익으면 연기가 난다 | 뒤집는다. 그때의 아랫면 익힘이 고정된다 |
| 윗면 굽는 중 | 뒤집은 붕어빵. 익을수록 색이 진해지고, 탈 때 검게 변하며 연기 | 꺼낸다. 진열대가 가득 차 있으면 꺼낼 수 없다(틀이 흔들리고 진열대가 빨갛게 깜빡인다) |

- 뒤집기 전에는 꺼낼 수 없다. 덜 익었을 때 탭하면 그대로 일찍 뒤집거나 일찍 꺼낸다(되돌리기 없음).
- 빵의 품질은 **두 면 중 나쁜 쪽**으로 정한다: 한 면이라도 탔으면 "탐", 아니면 한 면이라도 덜 익었으면 "덜 익음", 둘 다 알맞으면 "알맞음".
- 탄 빵도 꺼내면 진열대로 간다. 먹방 손님은 탄 빵도 먹는다([261021-02](./261021-02-fish-bun-customers.md)).

### 3-2. 익힘과 화력

- 빵마다 면별 익힘 값(정수)을 두고, 매 틱 그때의 굽는 속도만큼 더한다. 정수 연산만 쓴다(CLAUDE.md §4-3).
- 익힘 구간(한 면 기준, 화력 50일 때의 시간):

| 구간 | 시간(안) | 품질 |
|---|---|---|
| 덜 익음 | 0 ~ 4초 | 덜 익음 |
| 알맞음 | 4 ~ 6.5초 | 알맞음 |
| 탐 | 6.5초 이후 | 탐 |

- **화력** 0~100. 펌프 버튼을 누르고 있는 동안 초당 +40, 떼면 초당 −8씩 내려간다. 시작은 50.
- 굽는 속도 = 화력 0일 때 0.6배 ~ 화력 100일 때 1.6배(직선). 빨리 구울수록 알맞음 구간도 짧아진다. **속도와 정확도의 맞바꿈**이 펌프의 재미다.
- 위 시간·배율은 튜닝값이다. 원작 영상에서는 펌프질하면서 붓기부터 꺼내기까지 약 10초였다(3초 간격 관찰이라 대략값).
- 빵틀 재질·화구 강화가 이 값들을 바꾼다([261021-03](./261021-03-fish-bun-growth.md)).

### 3-3. 황금붕어빵

- 반죽을 부을 때 시드 난수로 **5%** 확률(강화로 오름)로 "황금 후보"가 된다.
- 황금 후보는 뒤집은 뒤 모양이 살짝 다르게 보인다(원작 규칙: "황금붕어빵이 될 붕어빵은 살짝 모양이 변합니다").
- 윗면이 알맞음 구간에 들어서는 순간부터 **0.6초** 반짝인다. 이때 꺼내면 **황금붕어빵**(값 3배, 손님 만족 최고).
- 반짝임을 놓치면 바로 탄다.

### 3-4. 진열대

- 꺼낸 빵이 진열대 왼쪽부터 쌓인다. 팔 때는 **먼저 꺼낸 빵부터** 나간다.
- 기본 12개까지. 강화로 늘린다. 빵마다 품질 표시(황금·알맞음·덜 익음·탐)를 색과 **모양**으로 같이 보여 준다(색만으로 구분하지 않는다).
- 진열대 끝의 **[탄 빵 버리기]** 버튼: 진열대의 탄 빵을 모두 버린다. 덜 익은 빵은 버리지 않는다(아깝지만 팔 수는 있다).

## 4. 판매

- 카운터에 손님이 **최대 3명** 선다. 손님마다 말풍선에 **주문 개수**(큰 숫자), 성격 표시, 기다림 막대를 보여 준다.
- 손님 아래 두 버튼:
  - **[N개 주기]**: 진열대 앞에서부터 N개를 준다.
  - **[+1 덤]**: N+1개를 준다. 하나는 공짜다.
  - 진열대 빵이 모자라면 버튼이 꺼지고 "빵 N개 필요"를 보여 준다. 나눠서 주지는 않는다.
- 받은 돈 = 주문한 빵의 값 합(품질 배율 적용) + 콤보 보너스. 덤으로 준 빵은 값을 받지 않는다.

| 품질 | 값 배율 |
|---|---|
| 황금 | 3 |
| 알맞음 | 1 |
| 덜 익음 | 0.5 |
| 탐 | 0.3 |

- 기본 빵 값은 120원(반죽 레시피 강화로 오른다). 손님 성격에 따른 만족·불만과 평판 변화는 [261021-02](./261021-02-fish-bun-customers.md).

### 4-1. 콤보

- 덤을 주고 손님이 만족 이상이면 콤보 +1.
- 덤 없이 팔거나, 손님이 아쉬움·불만이거나, 기다리다 떠나면 콤보 0.
- 콤보 보너스 = 받은 돈 × 콤보 × 10% (최대 100%).
- 덤은 빵 하나를 손해 보지만, 콤보가 이어지면 돈이 더 들어오고 평판도 오른다. 언제 덤을 줄지가 판매의 판단이다.

## 5. 화면 (`/play/fish-bun`, Phaser 4)

### 5-1. 배치

```
세로(휴대폰)                            가로(PC)
+--------------------------------+     +---------------------+-------------------------+
| 3일째  오후 2:40 [=====-----] [II] |     | 3일째 오후 2:40 [====]  12,340원 평판 Lv3   [II] |
| 12,340원           평판 Lv3     |     +---------------------+-------------------------+
+--------------------------------+     |  [틀][틀][틀][틀]      |  [손님]  [손님]  [손님]    |
|  (2)       (3)       (1)        |     |  [틀][틀][틀][틀]      |  [2개][+1] ...           |
| [손님]    [손님]    [손님]        |     |  [틀][틀][틀][틀]      |                         |
| [2개][+1] [3개][+1] [1개][+1]    |     |                      |  진열대 ●●●●●○○○○○       |
+--------------------------------+     |  [펌프]  화력 =====    |          [탄 빵 버리기]   |
| 진열대 ●●●●●○○○○○  [탄 빵 버리기]  |     +---------------------+-------------------------+
+--------------------------------+
|        [틀] [틀] [틀]            |
|        [틀] [틀] [틀]            |
|        [틀] [틀] [틀]            |
|        [틀] [틀] [틀]            |
+--------------------------------+
| [ 펌프 ]       화력 ======      |
+--------------------------------+
```

- 캔버스를 크게 잡고 화면에 맞춰 줄인다(Scale FIT). 게임 영역 비율에 따라 세로·가로 배치를 바꾼다(사과게임·복권 긁기와 같은 방식).
- 세로 배치에서 빵틀은 엄지가 닿는 아래쪽, 손님은 위쪽에 둔다. 펌프는 왼쪽 아래(왼손 엄지), 빵틀은 오른손 엄지로 누르는 배치를 기준으로 한다.
- 빵틀 한 칸은 휴대폰 세로 화면에서 폭 약 100px 이상(3열)이 되게 잡는다. 빵틀을 6칸으로 시작하면(강화 전) 칸을 더 크게 그린다.
- 상단 정보(날짜, 게임 시계와 하루 진행 막대, 돈, 평판)는 게임 화면 안에 그린다. 셸의 시간 막대는 쓰지 않는다([261021-04 §6](./261021-04-game-save.md)).

### 5-2. 조작

| 조작 | 동작 |
|---|---|
| 빵틀 탭 | 다음 동작(붓기·뒤집기·꺼내기) |
| 빵틀 위를 쓸어 넘기기 | **처음 누른 칸의 동작과 같은 동작**이 가능한 칸에만 차례로 한다. 빈 틀에서 시작하면 지나간 빈 틀에 모두 붓고, 굽는 중인 칸은 건드리지 않는다 |
| 펌프 누르고 있기 | 화력이 오른다. 펌프 손잡이가 오르내리는 연출 |
| [N개 주기] / [+1 덤] | 그 손님에게 판다 |
| [탄 빵 버리기] | 진열대의 탄 빵을 모두 버린다 |
| [II] | 일시정지(계속하기 / 오늘 장사 그만두기) |

- 누르는 순간 반응한다(복권 긁기 §3-7과 같은 원칙: 저지연 캔버스, 누를 때 바로 소리, 연출이 입력을 막지 않음).
- PC 키보드 단축키는 2차로 미룬다(§7).

### 5-3. 그림

- 모두 자체 제작 SVG를 텍스처로 굽는다. 이모지는 쓰지 않는다. 원작 그림(jar 안 이미지)은 참고로만 보고 따라 그리지 않는다.
- 붕어빵: 반죽 붓는 중, 아랫면 익힘 3단계(덜·알맞음·탐), 윗면 익힘 3단계, 황금 후보, 황금 반짝임. 빵틀은 무쇠 질감, 뚜껑 경첩.
- 손님: 6종 × 표정 3(보통·기쁨·화남). 성별·나이를 한쪽으로 몰지 않게 그린다([261021-02](./261021-02-fish-bun-customers.md)).
- 가게: 골목 포장마차 느낌의 배경, 시간에 따라 하늘색이 바뀐다(아침 → 노을 → 밤).
- 판 바탕·패널 색은 셸의 CSS 변수를 따르고, 가게 그림은 라이트·다크 모드에서 같다.

### 5-4. 소리

Web Audio로 합성한다(사과게임·복권 긁기와 같은 방식). 셸의 음소거·음량을 따른다.

| 때 | 소리 |
|---|---|
| 붓기 | 반죽이 떨어지는 "촥" |
| 굽는 중 | 빵틀 수에 따라 커지는 지글지글 잡음 |
| 뒤집기 | 무쇠 틀 닫히는 "착" |
| 꺼내기 | 짧은 "톡". 황금이면 반짝이는 소리 |
| 탐 | 낮은 "치익" |
| 펌프 | 공기 넣는 "슉" 반복 |
| 판매 | 금전등록기 "띵". 콤보가 오를수록 음이 올라간다 |
| 손님 화남·떠남 | 짧게 내려가는 두 음 |

## 6. 로직 (`games/fish-bun/src/logic`)

순수 TypeScript, 정수 연산과 시드 난수, 60틱 고정 간격. 서버도 이 코드로 하루를 다시 돌려 저장을 갱신한다([261021-04](./261021-04-game-save.md)).

| 함수 | 하는 일 |
|---|---|
| `createDay(state, seed)` | 저장 상태(강화·평판)와 시드로 하루를 준비한다. 손님 등장 시각·종류·주문 개수·황금 후보는 시드 난수로 정한다 |
| `step(day, input?)` | 한 틱 진행. 입력이 있으면 먼저 적용한다 |
| `replayDay(seed, inputs, state)` | 하루를 처음부터 다시 돌려 정산 결과와 다음 날 상태를 낸다 |

**입력 기록** — 짧게 `[틱, 동작, 값]` 배열로 남긴다(하루 입력이 수천 개까지 갈 수 있어서).

| 동작 | 값 | 실패 사유 |
|---|---|---|
| `tap` | 빵틀 번호 | 없는 칸·잠긴 칸 `bad_mold`, 돈 부족 붓기 `no_money`, 진열대 가득 `shelf_full` |
| `pump` | 1(누름) / 0(뗌) | 같은 값이 연달아 옴 `bad_pump` |
| `sell` | 손님 자리 × 2 + 덤 여부 | 빈 자리 `no_customer`, 진열대 부족 `no_stock` |
| `trash` | — | — |

- 쓸어 넘기기는 칸마다 `tap`으로 남는다. 손님 텍스트·연출은 화면(`scene`)만의 일이고 로직에 들어가지 않는다.
- 틱은 늘어나기만 해야 하고 10,800을 넘으면 안 된다(`bad_tick`). 같은 칸 `tap`은 6틱(0.1초) 간격 이상.
- 입력은 하루 최대 6,000개.
- 하루 점수 = **순이익**(매출 − 재료비, 0 미만이면 0). 랭킹은 [261021-05](./261021-05-growth-ranking.md).

## 9. 테스트

- 같은 저장 상태·시드·입력 → 같은 정산 결과와 다음 날 상태.
- 익힘: 뒤집는·꺼내는 틱에 따라 품질이 표대로 나온다. 화력 0·50·100에서 구간 시간이 배율대로 바뀐다.
