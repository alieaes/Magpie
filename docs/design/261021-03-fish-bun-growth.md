# 설계: 붕어빵 가게 — 성장(돈·평판·강화)

[붕어빵 가게](./261021-01-fish-bun.md)에서 하루 장사 사이에 남는 것들: 돈, 평판, 강화, 정산. 원작의 고양이 타이머 대신
**하루를 마칠 때마다 번 돈으로 가게를 키우는 것**이 목표가 된다. 저장과 검증은 [261021-04](./261021-04-game-save.md).

---

## 1. 시작 상태

| 항목 | 값 |
|---|---|
| 날짜 | 1일째 |
| 돈 | 1,000원 |
| 평판 | 0점, Lv1 |
| 빵틀 | 6칸(3 × 2) |
| 진열대 | 12개 |
| 반죽 재료비 | 한 번 붓는 데 50원 |
| 빵 값 | 120원(알맞음 기준) |

- **하루 시작 지원금**: 하루를 시작할 때 돈이 500원 미만이면 500원으로 채운다. 반죽을 못 부어 영영 장사를 못 하는 상태를 막는다. 정산표에 "운영 지원금"으로 보여 준다.

---

## 2. 평판

- 손님 결과마다 평판 점수가 오르내린다([261021-02 §2](./261021-02-fish-bun-customers.md)).
- 평판 레벨이 손님 간격·종류를 정한다([261021-02 §4](./261021-02-fish-bun-customers.md)). 일부 강화도 평판 레벨이 있어야 열린다(§3).
- **레벨은 내려가지 않는다.** 평판 점수는 지금 레벨의 기준점 아래로 떨어지지 않는다. 게임 오버가 없는 게임이라, 나쁜 하루가 이전 성과를 지우지 않게 한다.

| 레벨 | 필요 점수(누적) |
|---|---|
| Lv1 | 0 |
| Lv2 | 30 |
| Lv3 | 80 |
| Lv4 | 160 |
| Lv5 | 280 |
| Lv6 | 450 |
| Lv7 | 700 |
| Lv8 | 1,000 |
| Lv9 | 1,400 |
| Lv10 | 2,000 |

- 하루 손님 20명 안팎, 평균 +1.5점이면 하루 30점쯤 오른다. 레벨 기준은 튜닝값이다.

---

## 3. 강화 (1차 6종)

"가게 꾸리기" 화면에서 산다. 사는 즉시 저장된다([261021-04 §4](./261021-04-game-save.md)).

| 강화 | 효과 | 단계 | 비용(안) | 열리는 조건 |
|---|---|---|---|---|
| 빵틀 늘리기 | 6 → 9 → 12칸 | 2 | 3,000 / 12,000 | 9칸 평판 Lv2, 12칸 Lv4 |
| 빵틀 길들이기 | 알맞음 구간 +0.4초/단계 (2.5초 → 4.5초). 덜 타게 된다 | 5 | 1,500에서 단계마다 2배 | — |
| 화구 | 펌프를 떼면 내려가는 화력 속도 −20%/단계. 5단계는 떼도 화력 유지 | 5 | 2,000에서 2배 | — |
| 반죽 레시피 | 빵 값 +20원/단계 (120 → 220원), 황금 확률 +1%p/단계 (5 → 10%) | 5 | 2,500에서 2배 | — |
| 진열대 | 12 → 16 → 20 → 24개 | 3 | 2,000 / 6,000 / 18,000 | — |
| 간판 | 손님 간격 −8%/단계 | 5 | 2,000에서 2배 | — |

- 비용·효과 수치는 튜닝값이다. §6의 시뮬레이션으로 맞춘다.
- 강화는 되돌릴 수 없다(환불 없음).

### 3-1. 가게 꾸리기 화면

- 강화마다 카드 한 장: 그림, 이름, 지금 단계(●●○○○), 지금 효과 → 다음 효과, 비용, [강화] 버튼.
- 돈이 모자라거나 조건이 안 되면 버튼이 꺼지고 이유("평판 Lv4부터")를 보여 준다.
- 사면 카드가 반짝이고, 가게 그림에도 바로 반영한다(빵틀이 늘고, 간판이 바뀐다).

---

## 4. 정산

하루가 끝나면 보여 준다. 이 화면의 숫자는 서버가 같은 로직으로 다시 계산한 값과 같아야 저장된다([261021-04](./261021-04-game-save.md)).

```
3일째 장사 끝
  매출              8,420원   (팁·콤보 보너스 포함)
  재료비           −2,350원   (반죽 47번)
  ─────────────────────────
  하루 수익          6,070원   ← 랭킹 점수
  남은 빵 폐기          3개
  손님 22명   최고 3 · 만족 12 · 아쉬움 4 · 불만 1 · 떠남 2
  최대 콤보 6 · 황금붕어빵 2개
  평판 +31   Lv2 → Lv3   새 손님: 단골 어르신
  [가게 꾸리기]   [다음 날 장사]
```

- 하루 수익 = 매출 − 재료비. 0 미만이면 랭킹 점수는 0이다(돈은 실제로 줄어든다).
- 레벨이 오르면 새 손님·새로 열린 강화를 알려 준다.
- 비로그인 체험이면 맨 아래에 "로그인하면 가게가 저장돼요"와 로그인 버튼을 둔다([261021-04 §3](./261021-04-game-save.md)).

### 4-1. 남겨 두는 기록

저장 상태에 함께 남긴다: 일수, 누적 매출, 누적 판매 개수, 누적 황금붕어빵, 최고 하루 수익, 최대 콤보. 가게 화면과 2차 업적에 쓴다.

---

## 5. 2차 후보

1차를 해 보고 고른다. 모두 원작의 이름·생김새를 쓰지 않고 새로 만든다.

| 후보 | 내용 | 원작 대응 |
|---|---|---|
| 메뉴 늘리기 | 슈크림·고구마·피자 반죽. 손님이 메뉴를 골라 주문하고, 빵틀마다 반죽을 골라 붓는다 | 없음(새 요소) |
| 알바 | 자동 뒤집기 알바(알맞음에 뒤집음), 계산 알바(가장 오래 기다린 손님에게 덤 없이 자동 판매) | 펫의 도움 |
| 가게 마스코트 | 리뷰어 별을 모아 게이지가 차면 능력 발휘(예: 10초 동안 손님 기다림 멈춤, 모든 빵틀 화력 최대) | 펫(별 5개, 진화) |
| 소모품 | 하루 시작 전에 사는 버프(예: 오늘 황금 확률 2배, 오늘 손님 간격 −20%) | 아이템 |
| 업적·장사 일기 | 조건을 채우면 칭호와 한 줄 일기 | 장사일기·호칭 |
| 특별 손님 | 화나면 빵틀을 잠깐 못 쓰게 하는 손님, 외국어로 주문하는 관광객, 날씨·계절 손님 | 깡패, 외국인 |

## 6. 밸런스 목표

| 시점 | 목표 |
|---|---|
| 1일째 | 하루 수익 2,000~3,000원, 첫 강화 하나를 살 수 있다 |
| 3일째 안 | 빵틀 9칸 |
| 10일째 무렵 | 빵틀 12칸 |
| 30일째 무렵 | 1차 강화를 대부분 마친다. 이후 목표는 하루 수익 랭킹과 2차 요소 |

- 로직 테스트에 **흉내 플레이어**를 둔다: 정해진 실력(뒤집기·꺼내기 타이밍 오차, 덤 주는 기준)으로 하루를 돌리는 스크립트.
  여러 시드로 1~30일을 돌려 위 목표에 맞게 비용·효과를 고친다(복권 긁기 당첨표를 시뮬레이션으로 맞춘 것과 같은 방식).

---

## 7. 테스트

- 강화 구매: 돈 부족, 조건 미달, 최대 단계 초과는 실패. 성공하면 돈이 비용만큼 줄고 단계가 오른다.
- 평판: 레벨 기준점 아래로 내려가지 않는다. 기준을 넘는 하루 뒤 레벨이 오른다.
- 지원금: 하루 시작 때 500원 미만이면 500원이 된다.
- 정산: 매출 − 재료비 = 하루 수익. 하루 수익이 음수면 랭킹 점수 0.

---

## 8. 결정 사항

- [ ] 시작 상태: 1,000원, 빵틀 6칸, 재료비 50원, 빵 값 120원
- [ ] 평판 레벨은 내려가지 않는다
- [ ] 강화 1차 6종(§3). 수치는 시뮬레이션으로 조정
- [ ] 하루 시작 지원금 500원
- [ ] 2차 후보(§5)는 1차를 해 본 뒤 고른다
