# 설계: 수록 게임 1차 목록

유저가 준 참고 이미지 6장과 수박게임을 조사해서, Magpie에 넣을 게임과 각 게임의 규칙·점수 정의를 정한다.
이 문서의 "공통 요구사항"(§4)은 다음 설계인 프로젝트 골격(로비·로그인·점수 제출)의 입력이 된다.

참고 이미지는 광고 캡처라서 저작권 문제로 저장소에 넣지 않는다. 필요한 내용은 이 문서에 글로 옮긴다.

## 2. 조사 요약 — "가짜 광고 게임"이란

- 모바일 게임 광고 중에는 실제 게임에 없는 미니게임을 보여주는 광고가 많다. 광고에 낚인 유저들이 "광고 속 게임이 하고 싶다"고 하면서 하나의 밈이 됐다.
- 이 광고를 실제로 구현한 게임들도 이미 있다. 2024년 게임메카 기사에서 5종을 소개했다:
  러너형 선택지 전투(Crowd War), 러닝 슈팅(Arrow a Row), 핀 뽑기 퍼즐(Hero Wars 광고 원본), 핀 뽑기·숫자 탑·주차·색 분류 모음 등.
- Magpie는 이런 게임 여러 개를 **한곳에 모으고 랭킹으로 경쟁**하게 만든다는 점이 다르다.

## 3. 게임별 상세

### 3-1. 사과게임 (`apple-ten`) — 참고 이미지 6

**원본**: ゲーム菜園의 브라우저 게임 「フルーツボックス」(Fruit Box). 한국에서는 "사과게임"으로 유행했고 비슷한 앱이 여럿 있다.

**확인된 규칙**
- 17 × 10 = 사과 170개. 사과마다 1~9 숫자가 있다.
- 드래그로 사각형을 그려 사과를 고른다. 사각형 안 숫자 합이 **정확히 10**이면 그 사과들이 사라진다.
- 사과 1개당 1점. 제한 시간 120초.
- 참고 이미지(타이틀 화면)에는 옵션으로 "薄い色"(옅은 색)와 BGM 켜기/끄기, Reset 버튼이 있다.

**구현 방향**
- 원작 규칙을 그대로 따른다: 17 × 10, 120초, 1개당 1점.
- 세로 모바일에서는 판을 10 × 17로 돌려서 보여준다. 사과 개수와 점수 규칙은 같다.
- 판은 **시드로 생성**한다. 같은 시드면 같은 판이 나오므로, 서버가 입력 기록으로 점수를 다시 계산할 수 있다.
- 종료: 120초가 끝나면 끝난다. 더 만들 수 있는 조합이 없을 때를 위해 "끝내기" 버튼을 둔다.

**점수**: 제거한 사과 수. 0~170.

**비고**: 가장 단순하다. 골격 전체(로그인 → 플레이 → 점수 제출 → 랭킹)를 처음 검증하는 게임으로 쓴다.

### 3-2. 수박게임 (`fruit-merge`)

**원본**: Aladdin X의 「スイカゲーム」(Suika Game). 2021년 4월 프로젝터용으로 처음 나왔고 Switch판으로 유명해졌다.
원래 아이디어는 2021년 1월 중국 브라우저 게임 「合成大西瓜」(큰 수박 합치기)다.

**확인된 규칙**
- 과일 11단계: 체리 → 딸기 → 포도 → 데코폰 → 감 → 사과 → 배 → 복숭아 → 파인애플 → 멜론 → 수박.
- 떨어뜨릴 수 있는 과일은 작은 5종(체리~감)뿐이다. 다음에 나올 과일을 미리 보여준다.
- 같은 과일 두 개가 닿으면 다음 단계 과일 하나로 합쳐진다. 수박 두 개가 합쳐지면 둘 다 사라진다.
- 상자 위쪽 선을 넘으면 게임 오버.
- 점수: 합성할 때마다 점수를 얻고, 큰 과일일수록 점수가 크다. Switch판은 체리 1, 딸기 3, 포도 6, 데코폰 10, 감 15로 확인했다(삼각수 패턴). 이후 단계 값은 확인하지 못했다.

**구현 방향**
- 세로 화면. 가로 위치를 드래그로 정하고 손을 떼면 떨어진다.
- 물리는 Rapier 2D 결정적 빌드 ([기술 스택 설계 §3-5](./261006-03-tech-stack.md)).
- 단계 수, 과일 구성, 점수표는 **자체 정의**한다. 기본안은 원작처럼 11단계에 삼각수 점수(1, 3, 6, 10, ...)다.
- 그래픽은 자체 SVG 과일.

**점수**: 합성 점수 누적. 상한 없음.

**비고**: Rapier 결정적 빌드는 기기가 달라도 같은 입력이면 같은 결과가 나온다. 그래서 물리 게임이지만 서버가 입력 기록으로 점수를 다시 계산할 수 있다.

### 3-3. 칼날 모으기 (`blade-orbit`) — 참고 이미지 5

**원본**: 출처를 찾지 못했다. 회전하는 칼날로 쓸어버리는 "뱀서라이크"(중국에서는 割草, 풀베기 게임) 계열 광고로 보인다.
아래 규칙은 유저가 정의한 것이다.

**참고 이미지에 보이는 것**
- 잔디밭, 위에서 내려다보는 시점. 주인공 주위를 칼날 여러 개가 돈다.
- 숫자(66)가 적힌 둥근 오브젝트가 벽처럼 늘어서 있다. 숫자 = 체력.
- 위쪽에 칼날 아이콘이 든 버블(+99, +88).

**규칙 (유저 정의)**
- **시작**: 주인공 주위를 칼날 **1개**가 돈다.
- **칼날 늘리기** — 두 가지 방법:
  - 아이템: 버블 안에 "칼날 +n"이 들어 있다. 몸으로 닿으면 먹고, 칼날이 n개 늘어난다.
  - 오브젝트: 체력(숫자)을 갖고 있다. 칼날로 체력만큼 데미지를 주면 부서지면서 칼날 +n 아이템을 떨어뜨린다.
- **칼날끼리 충돌**: 서로 다른 캐릭터의 칼날이 부딪히면 부딪힌 칼날은 사라진다.
- **몸 충돌**: 칼날이 NPC 몸에 닿으면 그 NPC는 죽는다.
- **목표**: 최종 보스를 처치하면 클리어.

칼날끼리 부딪히면 사라지므로, 칼날이 많은 쪽이 상대 칼날을 다 깎아내고 몸에 닿는다.
결국 **칼날 수 싸움**이다. 숫자를 키워 더 큰 숫자를 이기는, 광고 게임의 전형적인 재미와 같다.

**해석해서 채운 부분 (확인 필요)**
- (a) 플레이어에게도 같은 규칙: NPC 칼날이 내 몸에 닿으면 게임 오버.
- (b) 칼날 충돌은 1:1 소모: 내 칼날 1개와 NPC 칼날 1개가 부딪히면 둘 다 사라진다.
- (c) NPC를 죽이면 남은 칼날 일부를 칼날 +n 아이템으로 떨어뜨린다.
- (d) NPC는 맵에 미리 배치되고, 정해진 칼날 수를 갖는다. 아이템을 먹고 크지는 않는다. 플레이어가 가까이 오면 쫓아온다.
- (e) 맵은 세로로 길다. 아래에서 출발해 위로 나아가고, 맨 끝에 보스가 있다.
- (f) 보스는 칼날이 아주 많은 큰 NPC다. 일정 시간마다 칼날을 조금씩 다시 채운다. 칼날을 충분히 모은 뒤 도전하게 만들기 위해서다.

**구현 방향**
- 이동: 모바일은 가상 조이스틱, PC는 WASD·방향키. 칼날은 자동으로 돈다.
- 칼날 배치: 칼날 수만큼 원 위에 같은 간격으로 놓고 일정 속도로 돌린다. 칼날이 많아지면 원을 키우거나 여러 겹으로 나눈다.
- 충돌: 칼날과 몸을 모두 원으로 보고 거리로 직접 계산한다. 물리 엔진은 쓰지 않는다.
  칼날이 수백 개까지 늘 수 있으므로, 맵을 칸으로 나눠 가까운 것끼리만 검사한다.
- 오브젝트 데미지: 칼날 하나가 닿을 때 1 데미지. 같은 칼날이 같은 오브젝트에 다시 데미지를 주려면 짧은 간격(예: 0.2초)이 지나야 한다. 수치는 튜닝값이다.
- 그래픽: 자체 SVG. 오브젝트는 자체 디자인 둥근 물체로 한다(원본의 두리안을 그대로 쓰지 않는다). 실존 브랜드 모양(음료 캔 등)은 쓰지 않는다.

**점수**: 미정. 후보:
- (가) 연속 스테이지: 보스를 잡으면 다음 스테이지로 간다. 갈수록 NPC와 보스가 강해진다. 점수 = 클리어한 스테이지 수.
- (나) 단판: 보스를 잡으면 끝난다. 점수 = NPC 처치·오브젝트 파괴 점수 + 남은 시간 보너스.

추천은 (가)다. 숫자 던전과 점수 방식이 같고, 다시 할 동기가 생긴다.

**비고**: 실시간 게임이지만 고정 간격 틱으로 짜면 서버가 입력 기록으로 다시 계산할 수 있다.
칼날이 도는 위치는 `Math.sin`/`Math.cos` 대신 미리 계산한 표로 구한다 (CLAUDE.md §4-3).

### 3-4. 숫자 던전 (`number-dungeon`) — 참고 이미지 4

**원본**: Hero Wars(Nexters) 광고. 실제 게임은 방치형 RPG다.
- 최근 광고는 던전 탐험형: 내 숫자보다 작은 몬스터를 잡으면 그 숫자를 더하고, 큰 몬스터와 붙으면 죽는다. 이 던전은 실제 게임 화면이 아니다.
- 예전 광고는 핀 뽑기 퍼즐이었다. 2019년 이후 일부 퍼즐·탑 미니게임은 실제 게임 이벤트로 들어갔다.

**참고 이미지에 보이는 것**
- 비스듬히 내려다보는 던전 맵. 주인공(20), 몬스터(8, 10, 32, 90, 100), 보물상자(10), 배수 아이템(×3, ×5), 금화 더미.
- 길이 갈라져 있어서 **어느 길로 갈지**가 핵심이다.

**구현 방향**
- 주인공은 힘(숫자)을 갖는다. 연결된 방으로만 이동한다(탭).
- 몬스터: 내 힘 > 몬스터 숫자면 이기고 그 숫자를 흡수한다. 같거나 작으면 진다(게임 오버).
- 아이템: 보물상자(+N), 배수(×N).
- 마지막 방에 보스가 있다. 보스를 잡으면 스테이지 클리어. 다음 스테이지는 숫자가 커지고 맵이 넓어진다.
- 스테이지는 **생성기**로 만든다. 정답 경로를 먼저 만들고 거꾸로 문제를 짜서, 항상 풀 수 있는 스테이지만 낸다.
- 랭킹 모드: 1스테이지부터 시작해 한 번 지면 끝나는 도전 모드.

**점수**: 클리어한 스테이지 수. 동점이면 먼저 달성한 사람이 위다.

**비고**: 결정적 게임이라 시드와 입력 기록으로 서버가 다시 계산할 수 있다.

### 3-5. 설원 캠프 (`frost-camp`) — 참고 이미지 3

**원본**: Whiteout Survival(Century Games) 광고. 실제 게임은 빙하기 생존 전략 게임이다.
광고와 실제 게임이 전혀 다르다는 평이 많고, 광고 덕분에 2024년 인앱 매출 10억 달러를 넘겼다는 분석이 있다.
광고는 "아이들 아케이드(돈을 모아 시설을 여는 방식) + 기지 건설 + 곤경에 처한 사람들"을 섞는다. 플레이어블 광고에서는 북극곰을 사냥해 고기를 마을 생존자에게 가져다준다.

**참고 이미지에 보이는 것**
- 눈 덮인 캠프, 위에서 내려다보는 시점. 왼쪽 아래 가상 조이스틱, 오른쪽 위 돈 카운터.
- 바닥에 구매 칸: 칼(45원), 구급상자(10원). 밟으면 돈을 내고 시설이나 장비를 연다.
- 울타리 안 북극곰, 고기를 기다리는 생존자, "판매" 테이블.

**구현 방향**
- 조이스틱 이동 → 곰 사냥 → 고기 운반·요리 → 생존자에게 판매 → 돈 → 구매 칸에서 시설 해금, 이 순환이 기본이다.
- 생존자가 제때 음식이나 온기를 못 받으면 얼어붙는다(광고의 "곤경" 요소).

**점수**: **미정.** 아이들 아케이드는 원래 끝이나 점수가 없다. 후보:
- (a) 제한 시간(예: 5분) 안에 번 돈
- (b) 한파 웨이브를 버틴 일수
- (c) 구한 생존자 수

**비고**: 시스템이 가장 많아서 마지막에 만든다.

## 4. 공통 요구사항 (골격 설계로 넘길 것)

| 항목 | 내용 |
|---|---|
| 화면 방향 | 세로 4종, 가로 1종(사과, 세로에선 판 회전). 각 게임이 선호 방향을 선언하고, 셸은 둘 다 지원한다. PC에서는 비율을 유지하고 여백을 둔다 |
| 입력 | 사각형 드래그(사과), 위치 드래그(수박), 가상 조이스틱(칼날·캠프), 탭 이동(던전) |
| 공통 모듈 후보 | 가상 조이스틱(칼날·캠프), 시드 난수 생성기(사과·던전) |
| 물리 | 수박게임만 Rapier 2D. 칼날은 거리 계산을 직접 한다. 나머지는 물리 없음 |
| 점수 형식 | 모두 정수, **높을수록 좋음**으로 통일. 동점이면 먼저 달성한 사람이 위 |
| 점수 단위 | 개(사과), 점(수박), 스테이지(던전, 칼날 (가)안). 캠프는 미정. 게임마다 표시 단위를 선언한다 |
| 판 길이 | 1~5분을 목표로 한다. 랭킹 게임은 한 판이 너무 길면 안 된다 |
| 점수 검증 | 모든 게임을 결정적 로직(시드 + 고정 간격 틱)으로 짜서, 서버가 입력 기록으로 다시 계산한다. 수박은 Rapier 결정적 빌드로 가능하다 |

**정규화 입력**: 게임마다 점수 크기가 아주 다르다. 사과 0~170, 수박은 상한 없음, 던전·칼날은 스테이지 수(수십). 총합 랭킹 정규화는 랭킹 설계에서 정한다.

## 5. 구현 순서와 이름

### 5-1. 구현 순서 (제안)

1. **사과게임** — 가장 단순하다. 골격 전체를 처음으로 끝까지 확인한다.
2. **수박게임** — 물리 엔진 도입을 확인한다.
3. **칼날 모으기** — 첫 광고 게임. 실시간 충돌과 가상 조이스틱(설원 캠프와 공용)을 여기서 만든다.
4. **숫자 던전** — 스테이지 생성기를 만든다.
5. **설원 캠프** — 규모가 가장 크다.

게임 하나 = 설계 문서 하나로 따로 쓴다. 이 문서는 목록과 방향만 정한다.

### 5-2. 나중에 넣을 후보

조사 중 나온 다른 광고 게임 장르. 1차 목록에는 넣지 않는다.

- 핀 뽑기 퍼즐 (Hero Wars 예전 광고)
- 주차장 탈출 (막힌 차를 순서대로 빼기)
- 색 분류 (물이나 공을 같은 색끼리 옮기기)

### 5-3. 제외한 게임

2026-10-06 유저 검토에서 재미가 없어 보인다는 이유로 뺐다.

| 게임 | 원본 | 내용 |
|---|---|---|
| 숫자 탑 | 탑 공략 광고 (Stick Hero 계열, 참고 이미지 2) | 내 힘보다 작은 적을 흡수하며 탑의 층을 순서대로 비우는 퍼즐. ×·÷·− 아이템 |
| 게이트 러너 | Last War: Survival 광고 (참고 이미지 1) | 자동 전진하며 ± 게이트로 병력을 늘리고 적 무리와 싸우는 러너 |

### 5-4. 표시 이름

원작 이름은 쓰지 않는다. "사과게임"은 한국에서 쓰는 통칭이라 원작 이름은 아니다.
"수박게임"은 원작 「スイカゲーム」을 그대로 번역한 이름이다. §6에서 정한다.
