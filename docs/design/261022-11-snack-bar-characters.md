# 설계: 분식집 — 캐릭터(직원) 해금

[분식집](./261022-09-snack-bar.md)에서 가게를 뛰어다니는 주인공을 여러 명 두고, 조건을 채우면 하나씩 열리게 한다.
원작의 주인공은 꾸미기 아이템을 사서 입히는 아바타였다(유료 재화, 능력 없음). 분식집은 그 대신 **생김새와 능력이 다른 직원**을 모으는 재미로 바꾼다.
그림은 [261022-12 도트 그림](./261022-12-snack-bar-pixel-art.md), 레벨·강화는 [261022-10](./261022-10-snack-bar-growth.md).

---

## 1. 규칙

- 직원(플레이어 캐릭터)은 모두 **2등신 사람**이다. 앞치마를 두른 같은 몸에, 얼굴·머리 모양·피부색과 **직원마다 다른 소품 하나**(요리사 모자, 나비넥타이, 고무장갑 등)가 붙는다. 사람끼리는 생김새 차이가 작아서, 소품으로 멀리서도 누군지 알아보게 한다.
- 피부색·머리 모양·나이는 고르게 섞는다(한쪽으로 몰지 않는다). 이름은 성별을 정하지 않는 별명으로 짓는다.
- 하루를 시작하기 전에 **오늘의 직원 한 명**을 고른다. 그날 장사 화면에서 그 직원이 걸어 다니고, 직원의 **능력 하나**가 그날 하루에 적용된다.
- 처음에는 까치 사장 한 명뿐이다. 나머지는 **조건을 채우면** 열린다. 돈으로 사지 않는다.
- 직원 바꾸기는 공짜이고 언제든(장사 중 말고) 할 수 있다. 저장은 가게 행동 `{ op: 'pick', id }`(잠긴 직원이면 `locked`).
- 능력에는 약점이 없다. 그날 가게 상황(대식가가 많다, 물이 바쁘다, 쟁반이 모자라다)에 맞는 직원을 고르는 것이 선택의 재미다.
- 손님(NPC)은 동물과 사람이 섞여 온다([261022-09 §5-1](./261022-09-snack-bar.md)). 직원은 사람만이다.

## 2. 직원 표 (1차 9명)

| id | 직원 | 생김새 · 소품 | 능력 | 열리는 조건 |
|---|---|---|---|---|
| `owner` | 까치 사장 | 짧은 갈색 머리, **빨간 두건**, 앞치마에 까치 배지 | 없음(기본) | 처음부터 |
| `runner` | 콩콩 | 삐죽한 검은 머리, **땀 흡수 머리띠**와 주황 운동화 | 걸음 −1틱(한 칸 더 빨리) | 가게 Lv2 |
| `water` | 졸졸 | 단발, **파란 두건**, 허리에 물병 | 물·단무지 한 번에 +1세트 | 물·단무지 100번 내기 |
| `server` | 척척 | 가르마 머리, **나비넥타이** | 쟁반 +1칸 | 김밥 100그릇 팔기 |
| `cleaner` | 뽀득 | 올림머리, **노란 머릿수건**과 분홍 고무장갑 | 닦기 2번이면 깨끗 | 테이블 200번 깨끗하게 하기 |
| `cook` | 보글 | **하얀 요리사 모자** | 모든 메뉴 연타 −1 | 대식가 30무리 받기 |
| `smile` | 방긋 | 곱슬 주황 머리, **큰 리본 머리핀** | 손님 기다림 막대 +15% | 기분 최고(+3)로 나간 손님 150명 |
| `talker` | 술술 | 짧은 머리, **베레모** | 팁 +10%p(기분 +2 이상 손님) | 하루 수익 60,000원 넘기기 |
| `master` | 손맛 어르신 | 하얀 곱슬머리, **동그란 안경** | 경험치 +20% | 30일째 장사 |

- 피부색은 직원마다 시안의 네 가지(밝은·중간·갈색·짙은 갈색)를 고르게 나눈다.
- 능력이 강화와 겹치면 더한다. 한계(쟁반 최대 6칸, 걸음 최소 4틱, 연타 최소 2번, 물·단무지 최대 3세트)는 [261022-10 §4](./261022-10-snack-bar-growth.md).
- 이름·능력·조건 수치는 튜닝값이다. 조건은 대략 2일째, 4~5일째, 1~2주, 30일째에 하나씩 열리도록 맞춘다([261022-10 §6](./261022-10-snack-bar-growth.md)).
- 누적 조건(물·김밥·닦기·대식가·기분 최고 손님)은 저장 상태의 `stats`·`sold`로 센다. 새 게임이라 모두 0부터 센다.

## 3. 직원 명부 화면

가게 화면의 [직원 고르기] 또는 정산의 [직원 고르기]로 연다.

```
+---------------------------------------------+
|  직원 명부                       6 / 9명     |
|  +---------+  +---------+  +---------+      |
|  | (그림)   |  | (그림)   |  | (그림)   |      |
|  | 까치 사장 |  | 콩콩     |  | 졸졸     |      |
|  | 능력 없음 |  | 걸음 빠름 |  | 물 2세트  |      |
|  | [오늘 직원]| | [고르기]  |  | [고르기]  |      |
|  +---------+  +---------+  +---------+      |
|  +---------+  +---------+  +---------+      |
|  | (실루엣)  |  | (실루엣)  |  | ...      |      |
|  |   ???    |  |   ???    |  |          |      |
|  | 김밥 100그릇 |  | 대식가 30무리 |  |       |      |
|  | [=====--] 64/100 | ...                    |
|  +---------+  +---------+  +---------+      |
+---------------------------------------------+
```

- 열린 직원: 도트 그림(제자리에서 통통 걷는 움직임), 이름, 능력 한 줄, [고르기]. 오늘의 직원은 테두리를 반짝이고 버튼 자리에 "오늘 직원".
- 잠긴 직원: 같은 모양의 **검은 실루엣**(소품 모양이 보여서 누가 올지 짐작할 수 있다), 이름 자리에 "???", 열리는 조건과 진행 막대(예: "김밥 64 / 100그릇"). 레벨 조건은 "가게 Lv2", 일수 조건은 "12 / 30일째".
- 세로 화면은 2열, 가로 화면은 3열 카드. 카드가 많아지면 세로로 넘긴다.
- 체험(비로그인)이면 고르기는 되지만 저장되지 않는다는 안내 줄을 둔다. 체험 하루는 늘 까치 사장으로 시작한다.

## 4. 열리는 순간

- 열리는 판단은 **하루 결과를 계산할 때** 로직이 한다(`replayDay`의 다음 날 상태에서 조건을 보고 `unlocked`에 더함). 서버가 같은 계산을 하므로 따로 확인할 것이 없다.
- 정산 화면 맨 아래에 "새 직원이 왔어요!" 칸: 새 직원이 문으로 걸어 들어와 꾸벅 인사하고 한 번 폴짝 뛴다. 짧은 팡파르. 그 아래 [오늘 직원으로](누르면 `pick`) 버튼.
- 한 번 열린 직원은 저장된 목록(`unlocked`)에 남는다. 나중에 조건 수치를 고쳐도 다시 잠기지 않는다.
- 가게 화면: 오늘의 직원이 가게 앞에 서 있고, 새로 열린 직원이 있으면 [직원 고르기] 버튼에 점이 붙는다(명부를 한 번 열면 사라짐. 화면에서만 기억, 저장하지 않음).

## 5. 로직·저장

| 위치 | 내용 |
|---|---|
| `logic/characters.ts` | 직원 표(id, 능력 값, 조건), 조건 확인 함수 |
| `createDay` | `state.character`의 능력을 그날 값(걸음 틱, 쟁반 칸, 연타 수, 물 세트, 닦기 수, 기다림 배율, 팁, 경험치 배율)에 더한다 |
| `replayDay` | 다음 날 상태를 만든 뒤 잠긴 직원의 조건을 보고 `unlocked`에 더한다. 정산 결과에 `newCharacters` |
| `applyAction` | `{ op: 'pick', id }`: 열린 직원이면 `character`를 바꾼다. 아니면 `locked`, 없는 id면 형식 오류 |
| 저장 상태 | `character`(문자열), `unlocked`(문자열 배열). 시작은 `owner`, `['owner']` |

- 생김새(머리 모양·피부색·소품)는 화면(`scene`)의 그림 표에만 있다. 로직은 id와 능력만 안다.

## 6. 2차 후보

| 후보 | 내용 | 원작 대응 |
|---|---|---|
| 알바 | 열린 직원 중 1~2명을 일당을 주고 그날 알바로 쓴다. 졸졸은 물 알바(몇 초마다 물 기다리는 테이블에 물), 뽀득은 청소 알바, 콩콩은 배달 알바처럼 직원마다 알바 일이 정해져 있다 | 배달·호객·물·청소 알바 |
| 배달 손님 | 배달 알바가 있으면 문 앞에 배달 주문이 들어온다 | 배달 알바 |
| 옷 색 바꾸기 | 직원마다 두건·앞치마 색을 고른다(팔레트만 바꾸면 되는 꾸미기). 업적 보상으로 열기 | 아바타 꾸미기 |
| 직원 더 늘리기 | 메뉴 S등급, 손님 1,000명 같은 긴 목표로 여는 직원 | — |

## 7. 테스트

- 조건 확인: 각 조건의 경계값에서 열린다, 한 번 열리면 계속 열려 있다.
- `pick`: 잠긴 직원 `locked`, 열린 직원이면 `character`가 바뀐다.
- 능력: 직원마다 그날 값이 표대로 바뀐다, 강화와 겹칠 때 한계값.
- 같은 시드·입력이라도 직원이 다르면 결과가 다르고, 같은 직원이면 같다.
