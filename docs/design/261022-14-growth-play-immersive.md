# 설계: 게임(성장형) 화면 몰입 — 머리줄 없애기, 소리는 게임 안 설정으로

게임(성장형, 붕어빵 가게 등)은 한 판으로 끝나는 미니게임과 달리 오래 머무는 곳이다. 몰입을 위해 게임 화면이 크게 보이도록
상단 바 아래의 **머리줄(게임 이름·체험 안내·소리·음량·나가기)을 없앤다.** 소리 설정은 게임 안으로 옮기고, 나가기는 상단 바(메인·랭킹)로 한다.
미니게임 화면(`PlayPage.vue`)은 그대로다.

---

## 1. 머리줄에 있던 것들의 새 자리

| 지금 머리줄 | 바뀐 뒤 |
|---|---|
| 게임 이름 | 없앤다. 게임 안 간판("까치 붕어빵")과 브라우저 탭 제목으로 충분하다 |
| 체험 안내("체험 · 로그인하면 가게가 저장돼요" / "닉네임을 정하면…") | 게임 안 가게 화면의 체험 안내 줄로 옮긴다. 문구는 셸이 정해 넘긴다(로그인 전 / 닉네임 전) |
| 소리 켜기·끄기, 음량 | 게임 안 **설정**으로 옮긴다(§2). 값은 지금처럼 브라우저에 저장하고 미니게임과 같은 값을 쓴다 |
| 나가기 | 없앤다. 상단 바의 로고·메인·랭킹으로 나간다. 장사 중이면 지금처럼 "장사를 그만둘까요?"를 한 번 묻는다(이동 가드), 탭을 닫거나 새로 고치면 브라우저가 묻는다 |

---

## 2. 게임 안 소리 설정 (붕어빵 가게)

- **가게 화면**: 오른쪽 위에 톱니 단추. 누르면 설정 창 — "소리" [켜짐/꺼짐], "음량" [−] 칸 막대(10칸) [+], [닫기].
- **장사 화면**: 시계 막대의 멈춤 단추로 뜨는 멈춤 창에 같은 소리 줄([켜짐/꺼짐], [−] 막대 [+])을 넣는다. 장사를 멈추지 않고 소리만 바꾸는 단추는 따로 두지 않는다.
- 음량 0으로 내리면 꺼짐, 꺼진 상태에서 올리면 켜짐(지금 셸 슬라이더와 같은 규칙).
- 바꾸면 게임이 셸에 알리고(`onSoundChange`), 셸이 브라우저에 저장한다. 다음에 열 때와 미니게임에서도 같은 값.
- 도트 그림체에 맞춘 단추·막대(지금 버튼·칸 막대 그대로)를 쓴다.

## 3. 화면 틀 (`GrowthPlayView.vue`)

| 크기 | 무대(게임 영역) |
|---|---|
| 폰(640px 미만) | 상단 바 아래 전체. 좌우 끝까지, 아래는 아이폰 홈 바 영역만 비운다 |
| PC | 상단 바 아래 높이 전체(위아래 16px 여백), 너비는 지금처럼 콘텐츠 폭(1200px) 안 가운데 |

- 불러오는 중·오류 표시는 지금처럼 무대 위에 겹친다.
- 개발용 시드 고정(`?seed=`) 안내는 머리줄 대신 콘솔에 한 줄 남긴다.
- [261022-13](./261022-13-play-fill-screen.md)의 셸 변경(무대가 남은 높이를 채움, 좌우 끝까지)은 게임 화면에서는 이 설계로 대신한다. 붕어빵 가게 캔버스 높이를 화면 비율에 맞추는 부분(13 §2-2)은 그대로 함께 한다 — 머리줄이 없어진 만큼 세로가 더 길어진다.

## 4. 게임 창구 변경 (`shared/src/game-module.ts`)

| 항목 | 변경 |

| `GrowthMountOptions.onSoundChange?(muted, volume)` | 게임 안 설정에서 소리를 바꾸면 셸에 알린다 (음량 0~1) |
| `GrowthSession.trialHint?` | 체험일 때 가게 화면에 보일 안내 문구("로그인하면 가게가 저장돼요" / "닉네임을 정하면 가게가 저장돼요") |

- 성장형 게임은 앞으로 소리 설정을 게임 안에 둬야 한다. 설계 중인 분식집([261022-09](./261022-09-snack-bar.md) 등)도 같은 창구를 따른다.

## 6. 확인

- 폰·PC에서 게임 화면에 머리줄이 없고 무대가 커졌는지, 상단 바로 나갈 때 장사 중이면 묻는지
- 가게 화면 설정 창·멈춤 창에서 소리 켜기/끄기·음량이 바로 들리고, 다시 열거나 사과게임으로 가도 같은 값인지
- 체험(로그인 전·닉네임 전) 안내 문구

## 8. 구현 메모 (2026-10-22)

설계대로 만들었다. 확정 규칙은 [saves 스펙 셸](../spec/saves.md), [fish-bun 스펙](../spec/fish-bun.md) "소리 설정".

- **루트 클래스를 `.growth-play`로 바꿨다.** `GrowthPlayView`는 `PlayPage`의 루트로 그려지는데, 부모의 scoped 스타일이 자식 루트에도 붙어서 `PlayPage`의 `.play` 여백(폰 10px)이 덮어쓰고 있었다.
- 음량 [-]로 0이 되면 꺼짐으로 바꾸되 음량 값은 기억하고, 꺼진 상태에서 [+]를 누르면 기억한 음량으로 켠다(처음엔 0에서 한 칸 올라 10%가 되던 것을 고쳤다).
- 설정 창은 바깥(어두운 부분)을 눌러도 닫힌다. 카드 안을 누르면 닫히지 않게 막았다.
- 톱니 단추는 캔버스 오른쪽 위(가게 그림 위). 세로·가로 배치 모두 같은 자리다.
- 화면 검증: PC에서 머리줄 없음·게임 영역 확대, 설정 창(끄기 → 저장 `magpie.muted=1`, 다시 열면 꺼진 상태, [+] 두 번 → 켜짐·80%), 장사 중 멈춤 창 소리 줄, 장사 중 상단 바 "메인" → "장사를 그만둘까요?" 확인. 폰(390 × 844)에서 게임 영역이 상단 바 아래 전체·좌우 끝까지(캔버스 비율은 261022-13에서 맞춘다). 체험 안내 문구(`trialHint`)는 로그인한 상태라 화면에서는 보지 못했다.
