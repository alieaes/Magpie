# 설계: 화면 손보기 (폰·PC 점검 결과)

인앱 브라우저에서 폰(375 × 812)과 PC(1440 × 900, 1366 × 768) 크기로 메인, 랭킹, 사과게임, 복권 긁기, 붕어빵 가게(가게·장사·가게 꾸리기)를 돌려 보고 어긋난 곳을 모았다.
가로 넘침(가로 스크롤)은 어느 화면에도 없었다.

---

## 1. 고칠 것

| # | 화면 | 크기 | 문제 | 고치는 방법 |
|---|---|---|---|---|
| 1 | 메인 "오늘의 랭킹" 패널 | 폰·PC 둘 다 | 제목 "오늘의 랭킹"이 두 줄로 꺾인다. 붕어빵 가게가 들어오며 대상 고르기 칸이 넓어져(가장 긴 이름 "붕어빵 가게") 머리줄이 모자라다 | 제목은 늘 한 줄. 자리가 모자라면 [대상 고르기]·[일간/역대]를 제목 아래 줄로 내린다 |
| 2 | 붕어빵 가게 — 가게 화면 | PC(가로 배치) | 오른쪽 끝 배경 건물이 가게 그림 밖으로 삐져나와 오른쪽 카드 사이 틈에 걸린다(건물 폭을 그림 영역에서 자르지 않음) | 건물을 그림 영역 안에서 자른다 |
| 3 | 붕어빵 가게 — 가게 화면 | PC(가로 배치) | 상태 카드(N일째 아침·가진 돈·평판·최고 하루 수익)가 고정 높이라 아래에 빈 공간이 크다 | 카드 높이를 내용에 맞추고, 버튼은 카드 바로 아래에 둔다(정산 카드와 같은 방식) |
| 4 | 붕어빵 가게 — 장사 화면 | 폰·PC 둘 다 | 손님 대사가 세 줄이면 말풍선을 넘쳐 개수 글자와 겹친다. 메뉴가 열린 뒤 대사가 길어져 생긴다(예: 리뷰어 "슈크림 두 개 / 주세요, 리뷰 쓰러 / 왔어요") | 대사 줄 수에 맞춰 말풍선을 위로 키운다(수수께끼 손님·관광객처럼). 꼬리 위치는 그대로 |

---

## 2. 확인했지만 문제가 아니었던 것

- 랭킹 페이지 탭(총합·사과게임·복권 긁기·붕어빵 가게): 폰에서도 한 줄. 기록이 있을 때 목록도 정상(개발 시드 기록으로 확인).
- 상단 바: 폰에서는 닉네임이 숨어서 12자 닉네임 + 관리자 표시여도 넘치지 않는다.
- 사과게임·복권 긁기: 폰·PC·1366 × 768에서 판이 화면 안에 들어오고, 게임 끝 카드도 정상.
- 붕어빵 가게 가게 꾸리기(폰), 로그인 창(폰·PC, 앞서 확인).
- 게임 끝난 뒤 시간 막대가 처음 시간으로 보이던 것: 인앱 브라우저 창이 뒤에 있어 게임 시간이 흐르지 않은 탓이었다(게임 중에도 같았다). 고칠 것 없음.
