# 진동(햅틱): 붕어빵 가게 탭·복권 긁기

상태: 제안 (유저 컨펌 대기) — §6 아이폰 최신 버전 대응은 정할 것

붕어빵 가게에서 빵틀을 누를 때와 복권을 긁을 때 폰에 짧은 진동을 준다.
안드로이드는 Vibration API, 아이폰은 스위치 우회 방법을 쓰고, 진동 함수와 켜고 끄는 설정은 `shared/`에 하나로 둔다.

## 1. 브라우저 사정 (2026-10-23 조사)

| 기기 | 방법 | 할 수 있는 것 |
|---|---|---|
| 안드로이드 크롬·삼성 인터넷·엣지 | `navigator.vibrate(ms)`, `navigator.vibrate([진동, 쉼, 진동, …])` | 길이·패턴 자유. 페이지를 한 번 누른 뒤로는 아무 때나 울릴 수 있다 |
| 안드로이드 파이어폭스 | 없음 (129에서 Vibration API를 뺐다는 자료가 있다) | — |
| 아이폰 iOS 17.4 ~ 26.4 | 숨긴 `<input type="checkbox" switch>`의 label을 코드로 `click()` | 아무 때나 '톡' 한 번. 길이·세기·패턴은 못 정한다 |
| 아이폰 iOS 26.5 이상 | 코드로 누른 클릭은 신뢰하지 않는 클릭으로 쳐서 햅틱이 없다. 손가락이 실제 스위치를 눌러야 한다 | 그 자리를 탭할 때만 '톡' 한 번 (§6) |
| PC·아이패드 | 없음 (아이패드는 진동 장치가 없다) | — |

- 유저가 알려 준 tactus(0.0.3, 2025-06)는 아이폰 셋째 줄 방식이다. 소스를 받아 보니 숨긴 스위치와 label을 만들어 두고 `label.click()`을 부른다.
  ios-haptics 0.x도 같은 방식이다. 그때는 됐지만 iOS 26.5부터 막혔다.
- ios-haptics 3.x 문서는 이제 "iOS 17.4 ~ 26.4에서만 된다"고 적고, 대신 스위치를 요소 위에 덮어 손가락이 직접 누르게 하는 방식을 낸다.
  다른 라이브러리·개발자들도 같은 내용을 실기기에서 확인했다고 보고한다(맨 아래 참고).
- 애플 공식 문서는 없다. 위 내용은 라이브러리 문서와 개발자들의 실기기 보고를 모은 것이다.

정리하면, **최신 iOS를 쓰는 아이폰은 코드로 누르는 우회 방법으로는 울리지 않는다.**
iOS 26.4 이하에 머문 아이폰(최신 iOS를 못 받는 옛 기종 포함)만 울린다. 최신 아이폰까지 울리게 하려면 §6이 필요하다.

## 2. 범위

- 넣는 곳: 붕어빵 가게 빵틀 탭(쓸어 넘기기 포함), 복권 긁기·칸 벗겨짐·결과.
- 공통 함수 `@magpie/shared/haptics`, 켜고 끄는 설정(미니게임 머리줄, 붕어빵 가게 게임 안 설정).
- 넣지 않는 것: 다른 게임(사과 게임·분식집 등)은 손대지 않는다. 함수가 생기면 각 게임 설계에서 따로 붙인다.
  붕어빵 가게의 펌프·판매·손님 반응도 이번 범위 밖이다.
- 진동은 화면(`scene`)에서만 부른다. `logic`은 건드리지 않으므로 서버가 판을 다시 돌리는 것과 상관없다.

## 3. 공통 함수 (`shared/src/haptics.ts`)

브라우저 전용이라 서버가 가져가는 `@magpie/shared`와 나눠 `@magpie/shared/haptics`로 낸다(`game-module`과 같은 방식).

```ts
export type HapticKind = 'tap' | 'tick' | 'deny' | 'good' | 'great' | 'thud';

/** 이 기기에서 쓸 방법. 'none'이면 haptic()은 아무것도 하지 않고 진동 설정도 숨긴다 */
export function hapticSupport(): 'vibrate' | 'ios-switch' | 'none';
/** 진동 한 번. 꺼졌거나 못 하는 기기면 조용히 넘어간다 */
export function haptic(kind: HapticKind): void;
/** 진동이 켜져 있는지 */
export function hapticsEnabled(): boolean;
/** 켜고 끈다. 브라우저에 저장하고 구독자에게 알린다 */
export function setHapticsEnabled(on: boolean): void;
/** 설정이 바뀌면 부른다(셸 버튼·게임 안 설정 갱신용). 해제 함수를 돌려준다 */
export function onHapticsChange(fn: (on: boolean) => void): () => void;
```

### 3-1. 종류

| 종류 | 안드로이드 (ms) | 아이폰 (17.4 ~ 26.4) | 쓰는 곳 |
|---|---|---|---|
| `tap` | 12 | 톡 | 빵틀 붓기·뒤집기·꺼내기·고치기, 복권 칸 벗겨짐 |
| `tick` | 8 (40ms에 한 번까지) | 없음 | 복권 긁는 동안 |
| `deny` | [15, 60, 15] | 없음 | 빵틀 거절(돈 부족·진열대 가득 등) |
| `good` | [20, 50, 35] | 톡 | 황금 붕어빵 꺼냄, 복권 4·5등 |
| `great` | [30, 40, 30, 40, 90] | 톡 | 복권 1~3등 |
| `thud` | 40 | 없음 | 복권 꽝 |

- 아이폰은 '톡' 하나뿐이라 성공과 실패를 구분할 수 없다. 그래서 실패 쪽(`deny`·`thud`)은 아이폰에서 울리지 않는다.
  `tick`도 아이폰에서는 뺀다. 긁는 동안 스위치를 1초에 수십 번 토글하게 되기 때문이다.
- 숫자는 처음 값이다. 실기기로 만져 보고 고칠 수 있게 표 하나(상수)로 둔다.
- 긴 패턴(`good`·`great`)이 도는 동안 들어온 `tick`은 건너뛴다. `vibrate`를 새로 부르면 돌던 패턴이 끊기기 때문이다.
- 안드로이드에서 페이지를 누르기 전에 `vibrate`를 부르면 브라우저가 막고 콘솔에 경고를 남긴다.
  `navigator.userActivation?.hasBeenActive`가 거짓이면 부르지 않는다.

### 3-2. 기기 판단

- `navigator.vibrate`가 함수면 `'vibrate'`.
- 아이폰(UA에 `iPhone`)이고 Safari 버전이 26.4 이하로 읽히면 `'ios-switch'`.
  iOS 26 UA는 OS 버전 자리가 고정 값이라고 알려져 있어, Safari 버전(`Version/26.4`)으로 읽는다.
  아이폰 크롬(`CriOS`)처럼 Safari 버전이 없는 UA는 구현할 때 실기기 UA로 확인한다.
- 26.5 이상이거나 버전을 못 읽는 아이폰, 아이패드, PC는 `'none'`. 울리지 않는데 진동 설정만 보이는 일을 막는다. §6을 하면 바뀐다.
- 아이폰 스위치는 처음 쓸 때 숨긴 스위치와 label을 한 번 만들어 두고 `label.click()`을 부른다(tactus와 같은 방식).
  20줄 남짓이라 라이브러리를 들이지 않고 직접 쓴다.

## 4. 켜고 끄기

- 기본은 켜짐이다. `localStorage`의 `magpie.haptics`(`'0'` 꺼짐, `'1'` 켜짐)에 저장하고, 저장소를 못 쓰면 켜짐으로 친다.
- 상태는 `shared/haptics`가 직접 들고 저장한다. 소리는 게임마다 소리 엔진이 따로 있어 셸이 값을 넘기지만(`muted`·`onSoundChange`),
  진동은 엔진이 공통 함수 하나라 셸과 게임이 같은 값을 바로 본다. 그래서 `GameMountOptions`·`GrowthMountOptions`는 바꾸지 않는다.
- `hapticSupport()`가 `'none'`이면 어디에도 진동 설정을 보이지 않는다(PC에서는 안 보인다).
- **미니게임**: 플레이 중 머리줄의 소리 버튼 옆에 진동 버튼(아이콘만, 소리 버튼과 같은 크기, 꺼지면 빗금).
  켜면 `tap`을 한 번 울려 켜진 것을 손으로 알려 준다. 셸은 `client/src/composables/useHaptics.ts`로 Vue 값에 이어 붙인다.
- **붕어빵 가게**: 가게 화면 설정 창과 장사 중 멈춤 창의 소리 줄 아래에 "진동 [켜짐/꺼짐]" 한 줄(`settings.ts`).
  설정 창 카드 높이는 420 → 약 500. 지원하지 않는 기기면 줄이 없고 창도 지금 크기 그대로다.

## 5. 넣는 곳

### 5-1. 붕어빵 가게 (`games/fish-bun/src/scene`)

Phaser는 터치를 브라우저 이벤트 안에서 바로 처리하고, `FishBunScene.tapMold`는 `applyInput` 결과를 그 자리에서 안다.
그래서 진동은 그림 갱신(`DayView.onPhaseChange`)이 아니라 `tapMold`에서 결과를 보고 부른다. 손가락이 닿는 순간과 진동이 어긋나지 않는다.

| 순간 | 종류 |
|---|---|
| 빵틀 탭이 받아들여짐 (붓기·뒤집기·꺼내기·깨진 틀 고치기 한 번) | `tap` |
| 꺼낸 빵이 황금 | `good` (`tap` 대신) |
| 거절 (`no_money`·`shelf_full`·`locked_menu` 등, 지금 빵틀이 흔들리는 경우) | `deny` |
| 너무 빨리 다시 누름 (`too_fast`) | 없음 |

- 쓸어 넘기기로 여러 칸을 지나면 칸마다 `tap`이다.

### 5-2. 복권 긁기 (`games/lucky-scratch/src/scene/LotteryScene.ts`)

| 순간 | 종류 | 자리 |
|---|---|---|
| 긁는 중 (은박이 실제로 벗겨질 때) | `tick` | `scratchSegment`의 `sfx.scratch(dist)` 옆 |
| 칸 하나가 벗겨짐 | `tap` | `revealCell` (한꺼번에 벗길 때는 한 번) |
| 당첨 4·5등 | `good` | 결과 연출의 `sfx.winSmall` 옆 |
| 당첨 1~3등 | `great` | `sfx.winMedium`·`winBig` 옆 |
| 꽝 | `thud` | 꽝 도장(`sfx.lose`, 화면 흔들림과 같이) |

- "한 번에 긁기"도 긁는 동안 `tick`이 난다(`stepSweep`).
- 안드로이드는 표 그대로 다 느껴진다. 옛 아이폰(17.4 ~ 26.4)은 칸 벗겨짐과 당첨만 '톡'.

## 6. 아이폰 iOS 26.5 이상: 실제 스위치 덮기 (정할 것)

최신 아이폰에서 울리게 하는 유일한 길은 손가락이 실제 스위치를 누르게 하는 것이다.
게임 캔버스 위 그 자리에 보이지 않는 스위치를 덮는다(`opacity: 0`. 모양을 지우면 햅틱도 사라진다는 보고가 있어 기본 모양은 그대로 둔다).

할 수 있는 것과 한계:

- 탭할 때만 된다. 스위치가 바뀌는 것은 클릭(손을 뗄 때)이라 진동도 손을 뗄 때 올 것으로 본다(실기기 확인 필요).
- 끌면(긁기·쓸어 넘기기) 클릭이 생기지 않아 울리지 않는다. 그래서 **최신 아이폰에서는 복권을 긁는 동안 진동이 없다.** 카드를 톡 누른 경우만 울린다.
- 결과를 보고 고를 수 없다. 덮은 자리를 누르면 늘 한 번 울린다(거절·황금 구분 없음).
- 붕어빵 가게는 빵틀판 영역 하나에 덮으면 된다.
- 캔버스 위에 DOM을 얹는 것이라 손볼 것이 많다.
  - Phaser는 캔버스가 아닌 곳에서 시작한 터치의 움직임(`touchmove`)을 받지 않는다(캔버스에만 듣는다).
    입력 대상(`input.touch.target`)을 게임 칸으로 바꾸고, 창 전체 이벤트(`input.windowEvents`)를 꺼서 같은 터치를 두 번 받지 않게 해야 한다.
  - 터치 뒤에 브라우저가 흉내 내는 마우스 이벤트가 Phaser에 두 번째 누름으로 들어갈 수 있다.
  - 멈춤 창·반죽 고르기처럼 캔버스 안에 뜨는 창 아래에서는 덮개를 치워야 하고, 화면 크기나 빵틀 수가 바뀌면 자리를 다시 맞춰야 한다.
  - 두 손가락(펌프를 누른 채 빵틀 탭)일 때 클릭이 생기는지 모른다.
- 개발 쪽에서는 아이폰 실기기로 확인할 수 없다.

안:

- **A (추천)** — 이번에는 §3~5만 한다(안드로이드 + 옛 아이폰). 최신 아이폰에는 진동 설정이 보이지 않고 울리지도 않는다.
  대신 개발용 시험 화면을 하나 만들어, 유저가 자기 아이폰으로 어떤 방식이 되는지 직접 확인한다. 그 결과를 보고 덮기를 따로 설계한다.
- **B** — 이번에 붕어빵 빵틀판 덮기까지 한다. 위의 손볼 것을 실기기 확인 없이 넣게 되어, 탭이 두 번 들어가거나 쓸어 넘기기가 깨질 위험이 있다.

시험 화면(A에 포함): 개발 빌드에서만 `/dev/haptics`.

- 종류별 `haptic()` 버튼, 코드로 누르는 방식 버튼.
- 덮은 스위치를 얹은 작은 Phaser 캔버스. 탭·끌기·Phaser가 받은 누름 수를 세어 보여 준다(두 번 들어가는지 확인).
- `navigator.userAgent`와 `hapticSupport()` 결과.
- 폰은 같은 와이파이에서 개발 서버로 연다(지금 개발 서버는 이 PC에서만 열리므로 `--host`로 띄운다).
