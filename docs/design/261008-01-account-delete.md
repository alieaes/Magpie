# 설계: 회원 탈퇴

로그인한 유저가 스스로 계정과 기록을 모두 지운다. [로그인 설계](./261006-07-login.md) §7에서 이어진다.

---

## 1. 흐름

```
상단 메뉴 "탈퇴" → 확인 창(닉네임을 그대로 입력) → DELETE /api/me → 로그아웃 상태로 메인
```

- 확인 창에는 지워지는 것을 적고, **닉네임을 똑같이 입력해야** 탈퇴 버튼이 켜진다. 잘못 누르는 것을 막는다.
  닉네임을 아직 안 정한 유저는 "탈퇴"라고 입력한다.
- 되돌릴 수 없다. 같은 Google 계정으로 다시 로그인하면 기록이 없는 새 유저로 시작한다.

---

## 2. 지우는 것

한 트랜잭션에서 아래를 모두 지운다.

| 표 | 지우는 것 |
|---|---|
| `best_daily`, `best_alltime` | 그 유저의 최고 기록 → 랭킹에서 바로 빠진다 |
| `play_replays`, `plays` | 그 유저의 판과 입력 기록 |
| `sessions` | 그 유저의 모든 세션 (다른 기기 로그인도 끝난다) |
| `users` | 유저 줄. 닉네임은 다른 사람이 쓸 수 있게 된다 |

- 지운 뒤 랭킹 캐시를 비운다. 다른 서버 프로세스는 10초 안에 따라온다.
- 남기는 것: 없음. 관리자 작업 기록([관리자 설계](./261008-02-admin.md))에 이 유저가 대상으로 남아 있으면 유저 번호만 남는다(이름·Google ID 없음).
- 다른 유저의 순위·환산점은 자동으로 다시 계산된다(랭킹은 조회할 때 계산하므로).

---

## 3. API

| 요청 | 본문 | 응답 |
|---|---|---|
| `DELETE /api/me` | `{ "confirm": "<닉네임 또는 '탈퇴'>" }` | `204`. 확인 문구가 다르면 `400`, 비로그인 `401` |

- 로그인 설계 §2의 요청 위조 방지(Origin 확인)를 그대로 받는다.
- 응답과 함께 세션 쿠키를 지운다.

---

## 4. 화면

- 상단 아바타 메뉴: 닉네임 변경 · 로그아웃 · **탈퇴**(빨간 글씨, 맨 아래).
- 확인 창: 제목 "탈퇴할까요?", 지워지는 것 목록(기록, 랭킹, 닉네임), 입력칸, "탈퇴" 버튼(빨강) · "취소".
- 탈퇴하면 메인으로 가고 "탈퇴했어요" 안내를 짧게 띄운다.

## 5. 결정 필요

- [ ] 확인 방법: 닉네임을 그대로 입력 (닉네임 전이면 "탈퇴")
- [ ] 판 기록·입력 기록까지 전부 지운다 (분석용으로도 남기지 않는다)
