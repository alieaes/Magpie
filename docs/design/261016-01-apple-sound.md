# 설계: 사과게임 소리

상태: 제안 (컨펌 대기)

## 1. 목적

사과게임에 소리가 없어 손맛이 약하다. 효과음 2종과 배경음 2종을 넣는다.

| 소리 | 언제 | 느낌 |
|---|---|---|
| 터짐 | 합이 10이라 사과가 지워질 때 | 경쾌한 "퐁". 한 번에 많이 지우면 음이 높아지고 겹쳐서 풍성해진다 |
| 실패 | 사각형을 그렸는데 합이 10이 아닐 때 | 낮고 짧은 "툭". 거슬리지 않게 작게 |
| 기본 배경음 | 플레이 중 | 가볍고 반복해도 질리지 않는 루프 |
| 긴박 배경음 | 남은 시간이 20초 이하일 때 | 같은 곡을 빠르고 긴장감 있게 바꿔서 이어 붙인다 |

선택 사항(같이 넣을지 컨펌 필요): 끝났을 때 짧은 종료음, 10초 이하 매 초 "똑" 소리.

## 2. 방식: 파일 없이 코드로 합성 (Web Audio API)

- 원작 소리를 쓰지 않는다(CLAUDE.md §4-3). 외부 음원 파일을 구해 오면 저작권·출처 관리가 필요해진다.
  그래서 **오실레이터와 엔벨로프로 직접 합성**한다. 음원 파일이 없으므로 용량이 늘지 않고 라이선스 문제도 없다.
- 배경음은 짧은 음계 패턴(코드 진행 + 멜로디 몇 마디)을 스케줄러로 반복 재생한다.
  긴박 모드는 같은 패턴을 템포 약 1.35배, 음 한 단계 위로 재생한다.
- 나중에 실제 음원(직접 제작·CC0)으로 바꾸고 싶어지면 `audio/` 모듈 안쪽만 교체하면 되게 한다.
- Phaser 내장 사운드는 쓰지 않는다. 파일 기반이라 합성에 맞지 않고, Web Audio를 직접 쓰는 편이 단순하다.

## 3. 구조

- `games/apple-ten/src/audio/` 신설 (게임 안에 둔다. 지금은 사과게임만 쓰므로 `shared/`로 올리지 않는다.
  두 번째 게임이 소리를 쓰게 되면 그때 공통 모듈로 뺀다).
  - `synth.ts` — 음 하나를 내는 함수(파형, 주파수, 길이, 엔벨로프), 마스터 볼륨.
  - `sfx.ts` — `playPop(count)`, `playMiss()`.
  - `bgm.ts` — `start()`, `setUrgent(on)`, `stop()`. 오디오 시계 기준 미리 스케줄(약 0.2초 앞)해서 끊김을 막는다.
- `AppleScene`이 호출한다. 호출 위치:
  - `onUp`에서 `removed > 0` → `playPop(removed)`, 합이 10이 아니고 선택된 사과가 있었으면 → `playMiss()`.
  - `update`에서 남은 시간이 20초 아래로 처음 내려가면 `setUrgent(true)`.
  - `finish`에서 `bgm.stop()`.
- **게임 로직(`logic/`)은 건드리지 않는다.** 소리는 화면(scene) 쪽에서만 낸다. 결정성·서버 재계산에 영향이 없다.
- 합이 0칸(빈 칸만 선택)처럼 아무 사과도 안 잡힌 드래그는 실패음을 내지 않는다.

## 4. 브라우저 제약과 음소거

- 브라우저는 소리를 사용자 동작 없이 재생하지 못한다. "시작" 버튼을 누른 뒤에 게임이 mount되므로
  그 흐름에서 `AudioContext`를 만들고, 상태가 `suspended`면 첫 포인터 입력에서 `resume()`한다.
- 탭이 가려져 판이 끝날 때(`visibilitychange`) 소리도 같이 멈춘다. `destroy`에서 컨텍스트를 닫는다.
- **음소거 버튼**을 플레이 중 막대(점수·시간 옆)에 둔다. 인라인 SVG 스피커 아이콘, 이모지 없음.
  상태는 `localStorage`에 저장해 다음 판에도 유지한다. 기본값은 소리 켜짐.
  - 셸(`PlayPage.vue`)이 버튼을 가지고, 게임에는 `GameModule` 핸들의 `setMuted(boolean)`으로 전달한다.
    `@magpie/shared/game-module`의 핸들에 선택 항목 `setMuted?`를 추가한다(다른 게임은 구현 안 해도 됨).
- 모바일: 무음 스위치(iOS)가 켜져 있으면 Web Audio 소리가 안 나올 수 있다. 정상 동작으로 보고 별도 처리하지 않는다.
- 마스터 볼륨은 작게(귀 아프지 않게) 고정하고, 볼륨 슬라이더는 이번 범위에 넣지 않는다.

## 5. 검증

- 소리 자체는 자동 테스트가 어렵다. `synth`의 순수 계산(음 높이 계산, 패턴 → 시각표)만 단위 테스트한다.
- 브라우저에서 직접 들어 보고 음량·길이를 조정한다. 컨펌 후 구현하면 한 번 들어보시고 느낌을 알려 주세요.
- 기존 로직 테스트(`logic.test.ts`)가 그대로 통과해야 한다.

## 6. 범위 밖

- 효과음/배경음 개별 끄기.
- 로비·다른 화면의 소리.
- 실제 음원 파일 제작·도입.

## 6-1. 추가 (구현 후 요청 반영)

- **종료음**: 판이 끝나면(시간 종료·끝내기) 짧게 올라가는 4음 "띠리링". 화면이 가려져서 끝난 경우는 내지 않는다.
- **볼륨 바**: 음소거 버튼 옆 슬라이더(0~100). 값은 `localStorage`(`magpie.volume`)에 저장, 기본 70.
  체감 음량에 맞게 제곱 곡선으로 마스터 볼륨에 반영한다. 셸 → 게임은 `GameMountOptions.volume?`, `GameInstance.setVolume?`.
- **실패음 개선**: 낮은 소리(170Hz)는 노트북·휴대폰 스피커에서 거의 안 들린다. 330Hz→220Hz로 올리고 음량을 키운다.
  사과가 하나도 안 잡힌 드래그는 계속 소리를 내지 않는다.
- 6장 "볼륨 슬라이더는 범위 밖"을 이 항목이 대체한다.
