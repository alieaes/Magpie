# 설계: 관리자 대시보드 — 페이지와 방문자

관리자만 보는 대시보드 페이지(`/admin`)를 만든다. 이 문서는 페이지 틀과 **방문자**(오늘 시간별 그래프, 전체 방문자)를 다룬다.
같은 페이지의 게임별 플레이 이력은 [261024-02 플레이 이력](./261024-02-admin-play-history.md)에서 다룬다.

지금은 방문을 어디에도 남기지 않는다. 방문을 세는 것부터 새로 만든다.

---

## 1. 방문자를 어떻게 세나

- **방문자 = 브라우저 하나가 하루(KST 00:00 ~ 24:00)에 한 번.** 같은 날 몇 번을 다시 열어도 한 명이다.
- 브라우저는 **방문자 쿠키**로 구분한다. 로그인과 상관없이 센다(비로그인도 센다).
- 세는 때: 앱이 뜰 때 부르는 `GET /api/me`. 화면이 자바스크립트로 뜨므로 대부분의 검색 로봇은 세지 않는다.
- **오늘** = KST 오늘 온 방문자 수. 일간 랭킹과 같은 하루다(`shared/src/time.ts`의 `kstDayKey`).
- **전체** = 날마다 센 방문자의 합(블로그 방문자 수와 같은 방식). 배포한 날부터 센다.

IP가 아니라 쿠키로 세는 까닭: 휴대폰 통신사는 여러 사람이 IP 하나를 같이 쓰고(덜 센다), 같은 사람도 IP가 자주 바뀐다(더 센다).
쿠키를 지우거나 다른 브라우저로 오면 다른 방문자가 된다.

### 방문자 쿠키

| 항목 | 값 |
|---|---|
| 이름 | 개발 `magpie_vid`, https `__Host-magpie_vid` (세션 쿠키와 같은 규칙, `server/src/auth/cookies.ts`) |
| 값 | 무작위 16바이트(base64url, 22자). 누구인지는 담지 않는다 |
| 기간 | 1년. 다시 와도 늘리지 않는다 |
| 옵션 | HttpOnly, SameSite=Lax, Path=/, https면 Secure |

- `GET /api/me`에 방문자 쿠키가 없거나 모양이 틀리면(22자 base64url이 아니면) 새로 만들어 응답에 붙인다.

### 표 `visits` (새)

| 열 | 내용 |
|---|---|
| `day` | DATE. KST 날짜 |
| `visitor_id` | CHAR(22). 쿠키 값 |
| `first_at` | DATETIME(3), UTC. 그날 처음 온 시각 |

- 기본 키 (`day`, `visitor_id`). `INSERT IGNORE`로 넣어 그날 이미 있으면 아무 일도 없다.
- IP·유저 번호는 남기지 않는다. 방문자 수에 필요 없다.
- 적기에 실패해도 `GET /api/me`는 그대로 답한다(로그만 남긴다).

## 2. 관리자 API

`GET /api/admin/visitors`

```json
{
  "today": { "day": "2026-10-24", "total": 37, "hourly": [0, 0, 1, 0, 0, 0, 0, 2, 3, 5, 4, 2, 6, 8, 6, 0, 0, 0, 0, 0, 0, 0, 0, 0] },
  "allTime": 1204
}
```

- `hourly[h]`: 오늘 KST `h`시에 처음 온 방문자 수(24칸). 합이 `total`이다.
- `allTime`: `visits`의 줄 수.
- 권한은 기존 관리자 API와 같다: 비로그인 `401 UNAUTHORIZED`, 관리자가 아니면 `403 FORBIDDEN`.
- 형식은 `shared/src/admin.ts`(새)의 `AdminVisitorsResponse`.

## 3. 화면

- 주소 `/admin`. 관리자가 아니면(비로그인 포함) 없는 페이지 화면(`NotFoundPage`)을 보여준다. 로그인 상태를 받기 전에는 아무것도 그리지 않는다.
- 들어가는 곳: 유저 메뉴 맨 위 **"관리자 대시보드"**(관리자만).
- 페이지를 열 때 한 번 불러온다.

```
┌ 관리자 대시보드 ─────────────────────────────────────┐
│ 방문자                                                │
│   오늘 37명            전체 1,204명                   │
│                                                       │
│                         ▆ █ ▆                         │
│                    ▃ ▅ ▄ ▂ ▆ █ ▆                       │
│       ▂      ▂ ▃ ▅ ▄ ▂ ▆ █ ▆                           │
│   ─────────────────────────────────────────────       │
│   0     3     6     9    12    15    18    21         │
├───────────────────────────────────────────────────────┤
│ 플레이 이력  (261024-02)                              │
└───────────────────────────────────────────────────────┘
```

- 그래프: 인라인 SVG 막대 24개, 아래에 0·3·6·…·21시 눈금. 막대에 마우스를 올리거나(폰은 누르면) "14시 · 8명".
- 0명인 시간은 막대 자리만 비워 둔다.
- 폰·PC 모두 한 줄 폭에 맞춰 막대 폭이 줄고 는다.

## 5. 테스트

- 서버
  - `GET /api/me`를 처음 부르면 방문자 쿠키를 주고 `visits`에 한 줄. 같은 쿠키로 다시 부르면 줄이 그대로, 모양이 틀린 쿠키면 새 쿠키.
  - 날짜 경계: UTC 14:59와 15:00(KST 23:59와 00:00)은 다른 날로 들어간다.
  - `GET /api/admin/visitors`: 비로그인 `401`, 일반 유저 `403`. `hourly`의 합이 `total`, `allTime`은 지난날까지 합친 수.
- 화면: 관리자로 `/admin` → 오늘·전체 수와 그래프. 일반 유저·비로그인은 없는 페이지. 유저 메뉴 항목은 관리자에게만. 폰·PC.

---

## 6. 검토한 대안

| 대안 | 내용 | 판단 |
|---|---|---|
| IP로 세기 | 쿠키가 필요 없다 | 통신사 IP 공유·변경으로 크게 어긋난다 |
| 외부 분석 도구(Google Analytics 등) | 그래프와 기능이 이미 있다 | 방문 정보가 바깥 서비스로 나가고, 대시보드 밖에서 봐야 한다 |
| 페이지 이동마다 세기(페이지뷰) | 많이 본 화면을 알 수 있다 | 요청은 방문자 수 |
