# 스펙: 사과게임 (`apple-ten`)

설계: [261006-09-apple-ten.md](../design/261006-09-apple-ten.md). 기록 모드(로그인 + 닉네임)와 연습 모드가 있다. 점수 제출은 [plays.md](./plays.md).

## 규칙 (`games/apple-ten/src/logic`)

- `rules.ts`: 규칙 함수와 상수. 화면(scene)은 이 파일만 가져간다.
- `index.ts`: `rules.ts`를 다시 내보내고, 서버용 `appleTenLogic`(`GameLogic`: 최대 7200틱, 최고 170점, 입력 형식 Zod, `replay`)을 더한다.
  Zod가 게임 번들에 들어가지 않게 나눴다. 서버는 `@magpie/game-apple-ten/logic`(= `index.ts`)을 쓴다.

| 항목 | 값 |
|---|---|
| 판 | 17 × 10 = 170칸. 칸마다 1~9. 인덱스 = r × 17 + c, 지워진 칸은 0 |
| 판 만들기 | `createBoard(seed)`: 시드 난수로 칸마다 1~9를 고르게 뽑는다. 다 풀 수 있는 판을 보장하지 않는다 |
| 선택 | 칸 좌표 사각형 `{ c1, r1, c2, r2 }`(양 끝 포함). 안의 합이 정확히 10이면 사과를 지운다. 지워진 칸은 0으로 친다 |
| 점수 | 지운 사과 1개당 1점. 0~170 |
| 시간 | 120초 = 7200틱 |

- `trySelect(board, rect)`: 합이 10이면 지우고 지운 개수, 아니면 판을 그대로 두고 0. 판 밖이거나 순서가 뒤집힌 사각형도 0.
- `replay(seed, inputs)`: 입력을 처음부터 다시 적용해 `{ ok, score, ticks }`. 실패 사유:

| 사유 | 경우 |
|---|---|
| `too_many_inputs` | 입력이 85개 초과 (한 번에 최소 2개가 지워지므로) |
| `bad_tick` | 틱이 정수가 아니거나, 줄어들거나, 7200을 넘음 |
| `bad_rect` | 판 밖이거나 c1 > c2, r1 > r2 |
| `no_match` | 그 선택으로 지워지는 사과가 없음 |

- 입력 기록: 사과가 실제로 지워진 선택만 `{ t, c1, r1, c2, r2 }`로 남긴다. `t`는 그때의 틱.
- 입력 형식(`appleTenLogic.inputSchema`): 0 이상 정수 다섯 개짜리 객체의 배열, 최대 85개. 범위·순서는 `replay`가 본다.
- 결정성: 정수 연산과 시드 난수(`shared/src/random.ts`)만 쓴다. 테스트: `games/apple-ten/test/logic.test.ts`.

## 시드 난수 (`shared/src/random.ts`)

- 시드 문자열 → cyrb128 해시(32비트 정수 4개) → xoshiro128**. `Math.imul`과 비트 연산만 쓴다.
- `randomSeed()`: 무작위 16바이트 → 16진 32자. 게임 로직 안에서는 부르지 않는다.
- 수열은 바꾸면 안 된다(저장된 판의 재계산이 달라진다). 테스트가 첫 값 4개를 고정해 둔다.

## 화면

### 게임 (`games/apple-ten/src/scene`, Phaser 4)

- 캔버스는 칸 96px(사과 지름 76px, 틈 20px, 둘레 여백 28px)로 크게 만들고 화면에 맞춰 줄인다(Scale FIT, 가운데). 가로 1688 × 1016, 세로 1016 × 1688.
  칸 배치 상수·`canvasSize`·선택 판정 `pickRect`는 Phaser를 쓰지 않는 `pick.ts`에 있다. 테스트: `games/apple-ten/test/pick.test.ts`.
- **판 방향**: 게임 영역이 세로로 길면 판을 전치해서(가로·세로를 맞바꿔) 10 × 17로 그린다. 로직 좌표는 그대로다. 영역 비율이 바뀌면 다시 맞춘다.
- **캔버스**: 불투명하게 띄우고 바탕을 셸의 `--bg`로 칠한다. 저지연 캔버스(`render.desynchronized`)로 띄워 선택 사각형이 포인터를 더 바짝 따라온다. 지원하지 않는 브라우저는 옵션을 무시한다.
- **드래그 선택** ([설계 261017-01 §2-1](../design/261017-01-apple-ten-feel.md)):
  - 누른 점 ~ 포인터 사각형을 청록 점선으로 그린다. 합계는 보여주지 않는다.
  - 사각형이 **사과 상자(사과 중심 ± 38px)에 조금이라도 걸치면** 그 사과를 선택하고 청록 테두리를 켠다. 사과 위 어디를 눌러 시작해도 그 사과가 들어가고, 사과 사이 틈은 어느 사과에도 속하지 않는다.
  - 누르는 순간 누른 사과에 테두리가 켜진다(틈을 누르면 없음).
  - 손을 떼면 뗀 좌표로 다시 판정해 로직 칸 사각형으로 `trySelect`에 넘긴다. 걸친 사과가 없으면 아무 일도 없다.
- **지워진 사과**: 숫자는 바로 숨기고, 몸통만 120ms 동안 제자리에서 0.6배로 작아지며 흐려진다. 연출 중에 화면 방향이 바뀌면 바로 치운다.
- 판 바탕·테두리·액센트 색은 셸의 CSS 변수(`--surface`, `--border-strong`, `--accent`)에서, 캔버스 바탕은 `--bg`에서 시작할 때 한 번 읽는다. 반투명 색은 바탕 위에 섞는다.
- 시간은 실제 경과 시간(`performance.now`)으로 틱을 센다. 7200틱이 되면 끝.
- 화면이 가려지면(`visibilitychange` → hidden) 판을 끝낸다.

### 소리 (`games/apple-ten/src/audio`)

설계: [261016-01-apple-sound.md](../design/261016-01-apple-sound.md). 음원 파일 없이 Web Audio 오실레이터로 합성한다.

| 소리 | 언제 |
|---|---|
| 터짐 | 합이 10이라 지워질 때. 많이 지울수록 높은 음에서 시작하고 4개 이상이면 3음 화음 |
| 실패 | 사과가 2개 이상 잡혔는데 합이 10이 아닐 때(330→220Hz 두 음). 빈 칸만 잡거나 사과 하나만 잡으면(탭 포함) 안 난다 |
| 기본 배경음 | 플레이 중 반복 (112bpm, 4마디 32스텝) |
| 긴박 배경음 | 남은 시간 20초 이하. 같은 자리에서 이어서 156bpm, 온음 높게 |
| 종료음 | 판이 끝날 때 올라가는 4음. 화면이 가려져 끝났으면 내지 않는다 |

- 악보(`music.ts`)는 순수 계산이고 소리 내기(`index.ts`의 `AppleAudio`)와 나눠 두었다. 테스트: `test/audio.test.ts`.
- 판이 끝나거나 화면이 가려지면 배경음이 멈추고, 게임을 내리면 오디오를 닫는다. 로직(`logic/`)은 소리와 무관하다.
- 브라우저 자동재생 제한 때문에 첫 포인터 입력에서 `resume()`한다.
- 음소거·음량: 플레이 중 막대의 스피커 버튼과 슬라이더(0~100, 기본 70, 제곱 곡선). 슬라이더를 0으로 내리면 음소거, 올리면 해제된다.
  `localStorage`(`magpie.muted`, `magpie.volume`)에 저장. 셸의 `GameInstance.setMuted?`·`setVolume?`와 `GameMountOptions.muted?`·`volume?`로 전달한다.

### 플레이 페이지 (`/play/:gameId`, `client/src/pages/PlayPage.vue`)

- `playable`이고 게임 코드가 등록된 게임(`client/src/games/registry.ts`)만 연다. 아니면 "페이지를 찾을 수 없어요".
- 시작 전: 게임 이름, 규칙 설명(`howTo`), 모드 안내([plays.md](./plays.md) 화면), "시작".
- 플레이 중: 남은 시간 막대(10초 이하면 빨강)와 초, 점수, 소리 켜기/끄기, "끝내기". 점수 이름은 게임 목록의 `scoreLabel`(없으면 "점수", 복권 긁기는 "소지금"). 게임 영역은 상단 바·머리줄을 뺀 화면 높이. 폰(640px 미만)에서는 화면을 세로로 나눠 머리줄 아래 남은 높이를 게임 영역이 모두 채우고, 좌우 끝까지 붙인다(아래는 홈 바 영역만, [261022-13](../design/261022-13-play-fill-screen.md)). 캔버스는 블록으로 놓아 아래 틈이 생기지 않게 한다.
- 끝: "시간 종료"(시간이 다 됨) 또는 "게임 끝", 점수, 기록 결과(기록 모드) 또는 "연습 모드라 기록은 남지 않아요", "다시 하기", "랭킹 보기"(사과게임 탭).
- 게임 영역에서는 페이지가 스크롤되지 않는다(`touch-action: none`).
- 개발 중에는 `?seed=`로 시드를 고정할 수 있다(연습 모드).

## 셸과 게임의 약속 (`@magpie/shared/game-module`)

- 게임 패키지 기본 내보내기 `GameModule.mount(parent, { seed, onHud, onEnd })` → `{ finish(), destroy() }`.
- `onHud({ score, timeLeftTicks?, timeLimitTicks? })`, `onEnd({ seed, inputs, ticks, score })`.
- 1초 = 60틱 (`TICKS_PER_SECOND`, `@magpie/shared`).
