# 스펙: 복권 긁기 (`lucky-scratch`)

설계: [261016-02-lucky-scratch.md](../design/261016-02-lucky-scratch.md). 기록 모드와 연습 모드는 사과게임과 같다. 점수 제출은 [plays.md](./plays.md).

## 규칙 (`games/lucky-scratch/src/logic`)

- `rules.ts`: 규칙 함수와 상수. 화면(scene)은 이 파일만 가져간다.
- `index.ts`: `rules.ts`를 다시 내보내고, 서버용 `luckyScratchLogic`(`GameLogic`: 최대 18,000틱, 최고 2,000,000,000점, 입력 형식 Zod, `replay`)을 더한다.

| 항목 | 값 |
|---|---|
| 시작 | 복권 10장, 소지금 0원 |
| 복권 | 3 × 3칸. 같은 그림 3개면 그 그림의 등수로 당첨, 당첨금이 소지금에 들어간다 |
| 구매 | 한 장 1,000원. 한 번에 1~10장(화면은 1·5·10장). 언제든 산다 |
| 한 판 상한 | 복권 200장(받은 10장 포함) |
| 시간 | 5분 = 18,000틱 |
| 점수 | 끝났을 때의 소지금(원). 긁지 않은 복권은 셈하지 않는다 |

### 당첨표 (`PRIZE_TABLE`, 100만 분의 몇)

| 등수 | 그림(번호) | 당첨금 | 가중치 |
|---|---|---|---|
| 1등 | 까치(0) | 10,000,000원 | 10 |
| 2등 | 왕관(1) | 1,000,000원 | 100 |
| 3등 | 보석(2) | 50,000원 | 2,000 |
| 4등 | 클로버(3) | 5,000원 | 50,000 |
| 5등 | 복주머니(4) | 1,000원 | 300,000 |
| 꽝 | — | 0원 | 나머지 647,890 |

한 장 기대 당첨금 850원. 최고 점수 = 200장 × 1등 = 20억(DB `INT` 안).

### 복권 만들기 (`drawTicket(seed, index)`)

- 장마다 시드 난수 `SeededRandom("${seed}#${index}")`를 새로 만든다. 어느 장이든 바로 만들 수 있다.
- 등수: `int(0, 999999)`를 당첨표 구간(1등부터)에 넣는다.
- 그림: 당첨 그림을 뺀 그림을 2개씩 넣은 묶음을 섞고, 당첨이면 당첨 그림 3개 + 앞 6개, 꽝이면 앞 9개. 9칸을 다시 섞는다(섞기는 Fisher–Yates).
  그래서 당첨은 3개짜리 그림이 정확히 하나(당첨 그림), 꽝은 없다.
- 결과: `{ index, rank, prize, symbols[9], winCells[3 또는 0] }`. 칸 인덱스 = 행 × 3 + 열.

### 상태와 입력 기록

- 상태 `{ money, tickets(가졌지만 안 긁은 장), scratched(긁은 장 = 다음 장 번호), owned(가진 적 있는 장) }`.
- 입력 기록: `{ t, op: 'scratch' }`(다음 장을 다 긁음) 또는 `{ t, op: 'buy', count }`. `t`는 그때의 틱.
- `replay(seed, inputs)` 실패 사유:

| 사유 | 경우 |
|---|---|
| `too_many_inputs` | 입력이 390개(긁기 200 + 사기 190) 초과 |
| `bad_tick` | 틱이 정수가 아니거나, 줄어들거나, 18,000을 넘음 |
| `no_ticket` | 남은 복권 없이 긁음 |
| `too_fast` | 직전 긁기와 15틱(0.25초) 미만 간격. 첫 장은 0틱이어도 된다 |
| `bad_count` | 장수가 1~10 정수가 아님 |
| `ticket_limit` | 200장을 넘게 삼 |
| `no_money` | 소지금이 모자람 |
| `bad_op` | 모르는 동작 |

- 점수 = 마지막 입력 뒤 소지금, `ticks` = 마지막 입력의 틱.
- 입력 형식(`luckyScratchLogic.inputSchema`): `op`로 나뉜 객체의 배열, 최대 390개. `count`는 1~10 정수.
- 테스트: `games/lucky-scratch/test/logic.test.ts`(그림 규칙 2만 장, 등수 분포 20만 장, 각 실패 사유), `server/test/judge.test.ts`(서버 검사 통과·거절).

## 화면 (`games/lucky-scratch/src/scene`, Phaser 4)

### 배치

| 배치 | 캔버스 | 카드(640 × 920) | 패널 |
|---|---|---|---|
| 가로 | 1560 × 1000 | 왼쪽 | 오른쪽 780 × 920 |
| 세로 | 720 × 1400 | 위 | 아래 640 × 396 |

- 게임 영역 너비가 높이 × 1.1보다 작으면 세로 배치. 영역 비율이 바뀌면 다시 배치한다. 캔버스는 화면에 맞춰 줄인다(Scale FIT, 가운데).
- 남은 복권(지금 카드 제외, 최대 4장)은 카드 뒤에 7px씩 어긋난 뒷면으로 쌓인다.
- 캔버스는 저지연(`desynchronized`)·불투명이고, 바탕색은 셸의 `--bg`. 패널 색은 셸의 CSS 변수에서 읽는다. 카드는 두 테마에서 같은 디자인이다.

### 그림 (`symbols.ts`, `art.ts`)

- 그림 5종·까치 문장·동전·소리 아이콘은 자체 제작 SVG. 시작할 때 캔버스로 구워 텍스처로 올린다(칸용 140px, 당첨표용 60px, 동전 56px).
- 카드 바탕(남색, 금 테두리, 물결무늬, 문장·제목, 당첨표, 긁는 판), 카드 뒷면, 은박(칸마다 은색 + 잔줄 + 돋을새김 물음표), 붓, 부스러기, 색종이, 반짝임, 빛, 꽝 도장은 캔버스 2D로 그린다.
- 일련번호 `No. <시드 앞 4자>-<장 번호 4자리>`는 장식이다.

### 긁기

- 누르는 순간 그 자리부터 긁힌다. 끌면 지난 위치와 지금 위치 사이를 10px마다 찍는다. 붓 반지름 34px(판정은 32px).
- 칸마다 10 × 10점으로 긁힌 정도를 세고, 50% 넘게 긁히면 그 칸 은박을 마저 벗긴다(번쩍임, 부스러기, 그림이 톡 튀어나옴).
- 은박은 카드마다 `RenderTexture` 하나에 그리고 붓 모양으로 지운다(`ERASE`).
- "한 번에 긁기"(버튼, 스페이스): 0.56초 동안 은박을 7줄 지그재그로 쓸고, 남은 칸을 모두 벗긴다.
- 9칸이 다 드러나면 로직에 긁기를 반영하고 입력을 남긴다. 직전 긁기와 15틱이 안 지났으면 지날 때까지 기다린다.

### 결과

| 결과 | 연출 | 보여 주는 시간 |
|---|---|---|
| 꽝 | 그림을 어둡게 누르고 빨간 "꽝" 도장, 살짝 흔들림 | 0.9초 |
| 5·4등 | 당첨 칸 등수 색 테두리·빛, 나머지 그림은 어둡게, 당첨표 칸 강조, 카드 머리에 "N등 당첨! +금액" 띠, 동전 3·6개가 소지금으로 날아감 | 1.15초 |
| 3등 | 위 + 반짝임, 동전 10개 | 1.7초 |
| 2·1등 | 위 + "대박! N등 당첨", 금빛 번쩍임, 흔들림, 색종이, 동전 18개 | 2.8초 |

- 등수 색: 1등 금 `#f2b632`, 2등 보라 `#a46bf5`, 3등 하늘 `#3fb4ea`, 4등 초록 `#4cb85a`, 5등 빨강 `#ec4f5c`.
- 보여 주는 중에 카드를 누르거나 "다음 복권"(버튼, 스페이스)을 누르면 바로 다음 장으로 넘어간다. 카드는 왼쪽 위로 날아가고 다음 장이 쌓인 데서 올라온다.
- 남은 복권이 없으면: 살 수 있으면 카드 자리에 "복권을 다 긁었어요"와 살 수 있는 구매 버튼·정산 버튼이 두근거린다. 파산하거나 200장을 다 긁었으면 안내를 1.5초 보여 주고 끝난다.

### 패널

- 소지금(동전이 내려앉을 때마다 올라감, 살 때는 굴러 내려가고 "-금액"이 떠오름), 남은 복권(지금 카드 포함), 소리 켜기·끄기.
- 구매 버튼 1·5·10장: 소지금이 모자라거나 200장을 넘으면 꺼진다.
- "한 번에 긁기"(결과를 보는 중이면 "다음 복권"), "정산하기". 남은 복권이 있으면 "긁지 않은 복권 N장은 무효가 돼요" 확인 창을 띄운다.
- 가로 배치는 "긁은 복권 N장 · 당첨 N회 · 최고 N등" 줄을 더 보여 준다. 최근 결과 10개를 칩으로 보여 준다.
- 버튼은 누르는 순간(pointerdown) 동작하고 눌린 모양이 된다.

### 소리 (`sound.ts`)

- 녹음 파일 없이 Web Audio로 합성한다(`latencyHint: 'interactive'`, 압축기 뒤 주 음량 0.8).
- 긁기: 계속 도는 흰 잡음 → 고역 1.4kHz → 대역 3.8kHz. 붓이 움직일 때마다 음량을 속도에 맞춰 올리고, 70ms 동안 움직임이 없으면 줄인다.
- 칸 벗겨짐 "샥", 버튼 "톡", 꺼진 버튼 "툭", 구매 "철컥-칭", 동전 "띵"(내려앉을수록 음이 올라감), 꽝 "쿵"+낮은 두 음, 5·4등 짧은 아르페지오, 3등 긴 아르페지오+반짝임, 2·1등 팡파르+동전 소리.
- 소리 끔 여부는 `localStorage['magpie.lucky-scratch.muted']`에 둔다. 저장소를 못 쓰면 켜짐.
- 오디오는 "시작"을 누른 직후 열고, 화면을 누를 때마다 다시 깨운다(브라우저 자동 재생 정책).

### 그 밖에

- 시간은 실제 경과 시간(`performance.now`)으로 센다. 18,000틱이 되면 끝.
- 화면이 가려지면(`visibilitychange` → hidden) 그 자리에서 끝난다(정산).
- 셸의 "끝내기"도 묻지 않고 바로 끝난다. 끝나면 긁지 않은 복권은 무효다.
- 로비 카드 그림: 반쯤 긁혀 까치 3개가 드러난 복권과 동전(`GameThumb.vue`, 바탕 `--tint-purple`).
