# 스펙: 붕어빵 가게 (`fish-bun`)

설계: [261021-01 핵심 플레이](../design/261021-01-fish-bun.md), [261021-02 손님](../design/261021-02-fish-bun-customers.md), [261021-03 성장](../design/261021-03-fish-bun-growth.md).
성장형 게임(`kind: 'growth'`)이라 저장·검증·셸 흐름은 [saves.md](./saves.md)를 따른다. 게임 안 간판은 "까치 붕어빵". 원작(붕어빵타이쿤3)의 이름·그림·소리·대사는 쓰지 않는다.

## 로직 (`games/fish-bun/src/logic`)

- `rules.ts`: 하루 시뮬레이션(굽기·화력·손님·판매·마감·정산)과 `replayDay`. `customers.ts`: 손님 표·만족 판정. `growth.ts`: 저장 상태·평판·강화.
- `index.ts`: 서버용 `fishBunLogic`(`GrowthLogic`, Zod 형식). 화면은 Zod가 번들에 들어가지 않게 `rules.ts`만 가져간다.
- 정수 연산, 시드 난수, 60틱 고정 간격만 쓴다. 손님은 `"${seed}#customers"`, 황금 후보는 `"${seed}#gold"` 난수를 따로 쓴다.

### 하루

| 항목 | 값 |
|---|---|
| 길이 | 10,800틱(3분). 게임 시계 10:00~22:00, 1분 = 15틱 |
| 새 손님 | 9,000틱(21:30)부터 오지 않는다 |
| 마감 | 남은 손님은 평판 변화 없이 떠나고, 진열대·빵틀에 남은 빵은 폐기(`wasted`) |
| 진행 순서 | 한 틱: 화력 → 빵틀 익힘 → 손님 기다림 → 새 손님 → 틱 +1 → (10,800이면) 마감 |
| 입력 적용 | 그 틱을 진행하기 전에 적용한다. `replayDay`는 입력의 틱까지 진행 → 적용, 끝나면 마감까지 진행해 정산 |
| 지원금 | 하루를 열 때 돈이 500원 미만이면 500원으로 채운다(`stats.subsidy`) |

### 굽기

- 빵틀 탭: 빈 틀 → 붓기(재료비 50원, 돈 부족이면 `no_money`), 아랫면 굽는 중 → 뒤집기, 윗면 굽는 중 → 꺼내기(진열대 가득이면 `shelf_full`). 같은 칸은 6틱 안에 다시 누를 수 없다(`too_fast`).
- 화력 0~6000(=0~100%), 시작 3000. 펌프를 누르고 있으면 틱마다 +40, 떼면 화구 단계만큼 내려간다(틱당 8·6·5·3·2·0).
- 굽는 속도 = 60 + ⌊화력 / 60⌋(틱마다 그 면의 익힘에 더함). 화력 50%면 110.
- 익힘 구간: 덜 익음 < 26,400 ≤ 알맞음 < 42,900 + 2,640 × 빵틀 길들이기 단계 ≤ 탐. 화력 50%에서 4초, 6.5초(+0.4초씩).
- 품질은 두 면 중 나쁜 쪽(탐 > 덜 익음 > 알맞음). 아랫면은 뒤집으면 더 익지 않는다.
- 황금 후보: 부을 때 천분율 50 + 20 × 황금 비법 단계. 윗면이 26,400~30,360(화력 50%에서 0.6초)일 때 꺼내면 황금(아랫면이 알맞을 때만). 지나면 바로 탄다.

### 손님

| 종류 | 주문 | 기다림 | 규칙 |
|---|---|---|---|
| 동네 손님 `regular` | 1~3 | 20초 | 기본 |
| 꼬마 `kid` | 1 | 20초 | 덤이 없으면 결과 상한 아쉬움 |
| 바쁜 직장인 `office` | 1~2 | 10초 | 더 늦게 온 손님에게 먼저 팔면 바로 떠남(불만 평판) |
| 단골 어르신 `elder` | 2~3 | 30초 | 탄 빵이 섞이면 불만. 모두 알맞음 이상이면 팁 20% |
| 먹방 크리에이터 `creator` | 3~5 | 20초 | 덜 익음·탐도 값 배율 1, 감점 없음 |
| 리뷰어 `reviewer` | 1~2 | 20초 | 평판 변화 3배 |

- 등장 표(평판 레벨별 간격·비율)는 `customers.ts`의 `ARRIVALS`. 간격은 간판 단계마다 8%씩 줄고 최소 60틱. 손님마다 [종류·주문 개수] → [다음 간격] 순서로 뽑는다.
- 카운터 3자리. 빈 자리가 없으면 다음 손님은 자리가 날 때까지 기다리고, 손님이 떠나면 다음 손님은 최소 60틱 뒤에 온다. 첫 손님은 120~240틱.
- 그날의 손님 표는 아침 평판 레벨로 정한다(하루 동안 바뀌지 않는다).

### 판매

- 입력 `sell`: 값 = 자리 × 2 + 덤(1). 진열대 앞(왼쪽)에서부터 주문 개수(덤이면 +1)를 준다. 손님 없음 `no_customer`, 진열대 부족 `no_stock`.
- 만족 점수: 황금 +2, 알맞음 0, 덜 익음 −1, 탐 −2 → +2 이상 최고, 0~1 만족, −1~−2 아쉬움, −3 이하 불만. 손님 규칙을 덧씌운다.
- 받는 돈: 주문한 빵(덤 제외)의 값 합. 빵 값 = 120 + 20 × 반죽 레시피 단계, 품질 배율 황금 3·알맞음 1·덜 익음 0.5·탐 0.3(정수 내림). 불만이면 절반, 최고면 팁 20%.
- 콤보: 덤을 주고 만족 이상이면 +1, 아니면 0(기다리다 떠남·먼저 안 줘서 떠남도 0). 보너스 = (값 + 팁) × min(콤보, 10) × 10%.
- 평판: 최고 +3, 만족 +2, 아쉬움 0, 불만 −3, 떠남 −2. 리뷰어 3배.
- `trash`: 진열대의 탄 빵을 모두 버린다(`trashed`).

### 정산과 저장 상태

- 하루 수익 = 매출 − 재료비. 하루 점수 = max(0, 하루 수익). 최고 점수 상한 1억.
- 평판은 지금 레벨의 기준점(0·30·80·160·280·450·700·1,000·1,400·2,000) 아래로 내려가지 않는다.
- 저장 상태(v1): `day`, `money`, `reputation`, `upgrades`(7종 단계), `stats`(누적 매출·판매·황금, 최고 하루 수익, 최대 콤보). 시작: 1일째, 1,000원, 평판 0.

### 입력 기록

`[틱, 동작, 값]` 배열, 하루 최대 6,000개. 동작 0 `tap`(빵틀 번호), 1 `pump`(1 누름 / 0 뗌, 같은 값 연속은 `bad_pump`), 2 `sell`, 3 `trash`. 틱은 줄어들면 안 되고 10,800 미만(`bad_tick`).

### 강화 (가게 행동 `{ op: 'upgrade', key }`)

| key | 이름 | 단계 | 비용 | 효과 |
|---|---|---|---|---|
| `molds` | 빵틀 늘리기 | 2 | 3,000 / 12,000 (평판 Lv2 / Lv4부터) | 6 → 9 → 12칸 |
| `seasoning` | 빵틀 길들이기 | 5 | 1,500부터 2배씩 | 알맞음 구간 +0.4초 |
| `burner` | 화구 | 5 | 2,000부터 2배씩 | 떼면 떨어지는 화력 감소, 5단계 유지 |
| `recipe` | 반죽 레시피 | 5 | 2,500부터 2배씩 | 빵 값 +20원 |
| `golden` | 황금 비법 | 5 | 3,000부터 2배씩 | 황금 확률 +2%p (5 → 15%) |
| `shelf` | 진열대 | 3 | 2,000 / 6,000 / 18,000 | 12 → 16 → 20 → 24개 |
| `sign` | 간판 | 5 | 2,000부터 2배씩 | 손님 간격 −8% |

실패 사유: `max_level`, `locked`(평판 부족), `no_money`.

## 화면 (`games/fish-bun/src/scene`, Phaser 4)

- 캔버스: 세로 720 × 1400(게임 영역이 가로 × 1.15보다 세로로 길 때), 가로 1560 × 1000. Scale FIT. 영역이 바뀌면 같은 상태로 배치를 다시 그린다.
- **가게 화면**: 가게 앞모습(차양·"까치 붕어빵" 간판·진열창), 몇 일째·가진 돈·평판 막대·최고 하루 수익, [장사 시작] [가게 꾸리기]. 체험이면 안내 줄, 체험 하루를 마치면 [로그인하고 저장하기] [다시 체험하기].
- **장사 화면**(`DayView.ts`): 위 시계 막대(날짜·게임 시계·평판·돈·멈춤), 카운터(시간에 따라 하늘색이 바뀜, 차양, 손님 3자리), 진열대(왼쪽이 먼저 나가는 빵, 품질은 색 + 별·점선·연기 모양) + [탄 빵 버리기], 빵틀(6칸까지 2열, 그 뒤 3열), 펌프·화력 계기·콤보(가로 배치는 오늘 매출·손님 기록 칸 추가).
  - 손님: 말풍선(주문 개수 + 성격 아이콘 + 대사 2.2초), 기다림 막대(30% 남으면 대사 한 번), [N개 주기](받을 돈 미리 보기) [+1 덤](꼬마면 깜빡임). 판매·떠남 때 표정(기쁨·보통·화남)과 대사, 받은 돈·콤보·평판이 떠오른다.
  - 빵틀: 익힘에 따라 두 그림을 섞어 색이 서서히 바뀐다. 알맞음엔 김, 탐엔 연기. 황금 후보는 꼬리·등지느러미 모양만 다르고, 반짝이는 동안에만 금색 + 빛.
  - 조작: 빵틀 탭, 쓸어 넘기기(처음 누른 칸과 같은 단계의 칸만), 펌프 누르고 있기(손가락 3개까지). 마감 30초 전부터 시계·막대가 주황.
- **정산 화면**: 매출·재료비·하루 수익·지원금·손님 결과·콤보·황금·폐기·평판(레벨업이면 새 손님·새 강화 안내), 저장 상태 줄. 저장하면 [가게 꾸리기] [다음 날 장사](바로 다음 날을 연다), 저장 실패면 [다시 보내기].
- **가게 꾸리기**: 강화 7종 카드(그림·단계 점·지금 → 다음 효과·비용 버튼, 평판 부족이면 "평판 LvN부터", 체험이면 "로그인 필요").
- 멈춤 창: [계속하기] [오늘 장사 그만두기]. 화면이 가려지면 자동으로 멈춘다. 마감하면 "마감!" 뒤 1.3초 후 정산.
- 하루 시계는 프레임 시간(한 프레임 최대 250ms)을 멈춘 시간 없이 더해 틱을 센다. 게임 시간이 실제보다 느려질 수는 있어도 빨라지지 않는다.
- 그림은 모두 자체 SVG(`art.ts`, `people.ts`: 손님 6종 × 생김새 2 × 표정 3). 대사는 `lines.ts`(요즘 말투, 상황마다 여러 개). 소리는 Web Audio 합성(`sound.ts`): 붓기·뒤집기·꺼내기·탐·반짝임·판매(콤보에 따라 음 상승)·화남·문 종·지글지글(굽는 칸 수)·펌프·팡파르.
