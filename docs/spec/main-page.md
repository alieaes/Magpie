## 상단 바

- 로고(AviaryHub 기본 아이콘 01 Open Arch, 청록 + "Magpie") → 메인. 메뉴 "메인", "랭킹". 지금 페이지는 청록 밑줄.
- 오른쪽: 비로그인이면 "로그인" 버튼(로그인 기능 전까지 비활성, "로그인은 곧 열려요"),
  로그인이면 닉네임 첫 글자 아바타 + 닉네임 → 메뉴(닉네임 변경, 로그아웃). Esc·바깥 클릭으로 닫힌다. 모바일은 아바타만.
- 화면 위에 붙어 있다(sticky). 높이 56px.

## 메인

- 위: 제목 "오늘은 어떤 게임?"과 한 줄 소개 "랭킹은 매일 밤 12시에 새로 시작해요."
- 게임 카드: `shared/src/games.ts` 순서대로, **`playable` 게임만** 보인다. `coming-soon` 게임은 로비에 나오지 않는다(2026-10-07 변경).
  - 그림(게임별 인라인 SVG, 4:3), 이름, 한 줄 설명. 누르면 `/play/<id>`.
  - 아래 줄에 "오늘 1위 N개"(없으면 "첫 기록에 도전"), 로그인했으면 "내 최고"(역대 최고).
  - `GameCard`는 `coming-soon` 모양(흐린 그림 + "준비 중")도 그릴 수 있지만 지금은 쓰지 않는다.
- 오늘의 랭킹 패널: 대상 선택(총합 + `playable` 게임, 선택지가 하나면 "총합" 글자만) + 일간/역대 전환.
  상위 10명. 1~3위 순위 숫자는 청록. 내 순위가 10위 밖이면 구분선 아래에 "나" 줄을 붙인다. "전체 랭킹 보기"는 같은 대상·기간으로 랭킹 페이지에.
  일간이면 KST 00:00이 지날 때 자동으로 다시 불러온다.
- 배치: 1024px 이상 두 단(게임 + 오른쪽 360px 패널, 패널은 스크롤 따라옴), 640~1023px 게임 3열 + 패널 아래, 640px 미만 게임 2열 + 패널 아래.

## 랭킹 페이지

- 대상 탭(총합 + `playable` 게임, 가로 스크롤), 일간/역대 전환. 바꾸면 주소 쿼리가 바뀐다(`replace`).
- 일간: "YYYY-MM-DD · 초기화까지 N시간 M분"(30초마다 갱신), 역대: "전체 기간".
- 총합 탭: "게임마다 1위를 1,000점으로 환산해 더한 점수예요" 설명.
- "N명 참여", 상위 100명 목록. 내 순위는 목록이 아니라 하단 고정 막대("내 순위 N위 · M점")로 보여준다.

## 상태

| 상태 | 화면 |
|---|---|
| 불러오는 중 | 회색 막대(패널 10줄, 페이지 12줄). 다시 불러올 때는 기존 목록을 흐리게 |
| 기록 없음 | "아직 오늘 기록이 없어요"(역대는 "아직 기록이 없어요"). 페이지에는 "게임하러 가기" 버튼 |
| 실패 | "랭킹을 불러오지 못했어요" + 다시 시도 |

## 디자인 토큰 (`client/src/styles/tokens.css`)

- 라이트·다크는 시스템 설정(`prefers-color-scheme`)을 따른다.
- 바탕 `#f7f6f3` / `#121314`, 카드 흰색 / `#1a1b1d`, 테두리 `#eaeaea` / 흰색 8%.
- 액센트 청록 `#0e7c86` / `#4fb8be`. 액센트는 활성 메뉴·탭, 1~3위 숫자, 내 순위 강조, 로고에만 쓴다.
- 글꼴 Pretendard Variable(직접 호스팅, 동적 서브셋). 점수 숫자는 고정폭 숫자.
- 모서리: 버튼·입력 8px, 카드·패널 12px. 아이콘 Phosphor Bold.
- 카드·패널이 차례로 떠오르는 효과(600ms). 움직임 줄이기 설정이면 끈다.
